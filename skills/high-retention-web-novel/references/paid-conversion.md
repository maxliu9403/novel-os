# 免费微弧与自然付费转化

- 日期：2026-07-23
- 执行者：Codex
- 适用：免费试读规划、付费节点诊断、免费末章和首个付费章写作

## 1. 转化定义

付费续读欲望来自四项合力：

- **已感知价值**：免费内容已经兑现了题材承诺；
- **人物投入**：读者在意某人的选择、关系或身份；
- **具体期待**：读者知道下一阶段要处理什么后果；
- **叙事信用**：作者此前的问题得到过公平答案。

任何机制若提高好奇却损害叙事信用，长期价值为负。付费节点的目标不是让读者“因为没读完一句话而被迫购买”，而是让读者“因为刚完成一次有价值的体验，主动进入更高承诺阶段”。

## 2. 免费窗口不是固定章数

不要把某个平台或样本的 4–5 章直接固化成规则。免费窗口由里程碑决定：

1. 高概念已在事件中出现；
2. 主角展现了能力、脆弱和主动选择；
3. 核心关系或核心问题已经值得投入；
4. 至少一个短期问题已兑现；
5. 出现一个只有这部故事能提供的代表性场景；
6. 主角跨过不可逆门槛，下一阶段目标清晰。

平台只给固定章数时，反向设计每章工作，让上述里程碑在窗口内自然完成；不要把正常一章拆碎来适配数量。

用户已经确认总篇幅、单章篇幅或免费窗口时，把它们视为产品约束。不得为了制造更陡的付费点擅自增删章节、缩短正常兑现或用重复内心戏和无功能场景填满配额；应在约束内重建选择、代价和兑现密度。

## 3. 免费微弧

用 `F1 ... Fn` 规划，不预设 `n`：

| 位置 | 主要任务 | 必须提供的价值 | 离开状态 |
| --- | --- | --- | --- |
| F1 | 前提碰撞 | 独特钩子、即时目标、主角能力与代价 | 主角选择介入 |
| F2 | 策略测试 | 关系张力、规则后果、第一次反馈 | 一个假设被削弱 |
| F3... | 压力与换义 | 代表场景、旧细节新含义、退路缩小 | 主角承担更高成本 |
| Fn | 阶段兑现 | 回答旧问题、完成局部目标或重定义关系 | 不可逆门槛与具体新目标 |

免费末章不是预告片，它是第一幕或第一个微弧的结局。即使读者停在这里，也应感到读到了一段完整、有意义的故事；继续付费则是进入更深阶段。

## 4. 自然付费门槛

优先选择以下门槛：

- 主角主动跨过危险但合理的边界；
- 阶段胜利暴露此前未理解的代价；
- 一个答案重新定义核心关系；
- 原目标完成，但后果产生更具体的新目标；
- 主角公开站队，失去中立或退路；
- 关键资源到手，同时改变谁掌握权力。

合格门槛是不可跳步的连续链：

1. **兑现**：本章已经回答或完成一件读者在意的事；
2. **主动选择**：答案迫使主角在两个有代价的方向间作出决定；
3. **可见后果**：本章内展示该选择造成的不可逆状态变化，而不把后果全部推迟到锁章之后；
4. **明确压力**：下一章要处理的目标、对手、时限或关系风险可被一句话说清。

答案本身不能代替选择，宣布“我要调查”也不能代替后果。选择必须关闭旧退路或改变知识、权力、关系、资源、身份、规则或时限中的至少一项。

若结尾可随意移到上一页或下一页，说明它只是截断，不是门槛。

## 5. 首个付费章契约

首个付费章开场必须承接免费末章的直接后果。建议结构：

1. 在开场场景中展示门槛的即时后果；
2. 让主角采取承诺过的下一行动；
3. 对免费末章的新问题提供第一份实质信息；
4. 让成本或关系发生新的可观察变化；
5. 再打开后续支线。

不要切换到无关人物、长篇回忆或另一个地点来拖延兑现。读者第一次付费购买的不只是更多字数，而是作者履行上一章承诺的可信度。

## 6. 付费桥台账

```text
免费窗口长度或平台约束：
已证明的独特承诺：
已投入的核心人物/关系：
已兑现的短期问题：
免费末章关键选择：
不可逆状态变化：
下一阶段具体目标：
读者合理期待的首个付费章场景：
首个付费章实际兑现：
后续升级维度：
```

任何付费节点设计都先填此台账。无法填出“已兑现的短期问题”或“首个付费章实际兑现”时，付费点尚未成熟。

## 7. 章级留存循环

每章同时维护三种余额：

- **价值余额**：本章给了什么独特体验、答案或人物变化？
- **投资余额**：人物选择让读者更在意什么？
- **期待余额**：下一步具体后果是什么？

不能只增加期待余额。连续两章没有价值兑现时，优先回答问题、完成目标或改变关系，而不是再加秘密。

## 8. 诊断测试

对拟定付费点逐项回答：

- 删除最后一段，前面的章节是否仍有完整变化？
- 阶段答案是否迫使主角作出有代价的选择？
- 结尾危机是否由该选择直接触发，并已在本章出现可见后果？
- 至少一个旧问题已得到答案吗？
- 新压力是否能落到具体目标、对手、期限或关系风险，而不是“还有秘密”？
- 读者是否已看见题材最独特的一类场景？
- 首个付费章是否马上处理免费章后果？
- 付费前后是否保持同一主线、视角承诺与情绪承诺？
- 这个节点是否尊重正常章节完整性？

任一核心项为否，调整弧线或节点，而不是加一句更夸张的悬念文案。

## 9. 禁止模式

- 中句、动作中途或对话回答前强行截断；
- 连续制造未知，却长期不回答旧问题；
- 把一章拆成多个短片段以增加解锁次数；
- 用无铺垫的短信、电话、监控或陌生角色救场；
- 免费末章承诺 A，付费章转去无关支线 B；
- 依赖虚假文案，如“下一章她的人生彻底改变”；
- 反复羞辱、伤害或误会人物，只为延长追读；
- 把“读者没看懂”误当成“悬念很强”。

这些手段可能制造瞬时点击，却削弱信任、口碑和长期留存，不属于本 Skill 的转化方法。
