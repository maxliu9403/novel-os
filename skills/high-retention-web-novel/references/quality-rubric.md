# 质量量表与诊断流程

- 日期：2026-09-30
- 执行者：Codex
- 适用：交付前自检、`diagnose`、版本对比和评测

## 1. 先定审查范围，再查硬失败

先记录被评对象（设计、大纲、章节正文或完整篇章）、可见材料、章节功能、用户约束和缺失上下文。静场、余波章、过渡章、非主角 POV 章可以通过人物理解、情感意义、主题体验或关系变化提供价值，不必每章制造外部爆点、主角决断或不可逆危机。判断应落在正文实际产生的效果，不能只引用作者声称的功能。

以下问题在相关功能适用且证据充分时属于硬失败，不因其他分数高而通过：

- 全章既没有推进，也没有可指认的人物理解、情感意义、关系变化、主题体验或其他阅读价值，只重复已经完成的功能；
- 存在关键反转，却没有可回看的事实与成立的动机；
- 核心行动转折依赖临时救场或人物无依据改主意，破坏既有因果；不因非主角 POV、受制状态或余波章缺少主角决断而判失败；
- 在已承诺的悬念范围内长期只挖不填，或实际付费点是任意截断；
- 声称到达自然付费点，却没有依次出现阶段兑现、主角有代价选择、本章可见后果和具体下一压力；
- 首个付费章不承接免费末章的直接后果；
- 时间线、世界规则或人物已知事实与已确认 `project_canon` 出现无法解释的冲突；
- 可识别地复刻具体作品、角色、桥段链、独特措辞或在世作者风格；
- 将 `reference_only` 素材的正文、角色、特色场景、揭示或转折链当成项目 canon，或仅换名字后进入成稿；
- 内容越过用户明确的受众或内容边界。

保留 `reference_only`、`user_constraint`、`project_canon` 的输入分流：用户约束可以约束新设计，参考作品不能据此变成 canon。缺少前文或事实未确认时，写清不确定项和需要核对的材料，不把“当前材料没有交代”直接判成连续性错误，也不能当作已通过。

## 2. 0–4 分诊断量表

量表用来定位问题和比较修改，不是自动交付阈值，不预测商业结果。每个分数必须附被评对象中的实际证据；1、3 分表示相邻锚点之间的表现。

| 维度 | 0 分 | 2 分 | 4 分 |
| --- | --- | --- | --- |
| 高概念清晰度 | 无法复述 | 有设定但冲突产能有限 | 谁、目标、限制、代价、长线产能清晰 |
| 即时目标与代价 | 无方向 | 目标或代价模糊 | 目标可观察，选择两边都有真实代价 |
| 人物能动性 | 关键行动无依据或只靠救场 | 行动与反馈联系较弱 | 承担本章行动功能的人物，其选择与反馈可信且有效 |
| 因果密度 | 事件并列 | 部分因果，仍靠巧合 | 行动、反馈、新行动连续驱动 |
| 人物复杂度 | 标签或脸谱 | 有矛盾但不影响行为 | 欲望、能力、边界和冲突共同塑造选择 |
| 情感投入 | 抽象宣称 | 有关系信息但体验薄弱 | 具体经历、感知与反应让读者理解人物在意之物 |
| 状态变化与章节收益 | 无推进或阅读价值 | 变化或收益存在但展开不足 | 与本章功能相称的变化或阅读收益充分成立，并有前后证据 |
| 悬念公平性 | 叙述作弊 | 有线索但弱 | 事实可见、误读合理、新解释改变选择 |
| 兑现可靠性 | 只挖不填 | 局部推进 | 回答旧问题并让答案产生新后果 |
| 升级多样性 | 只增战力/伤害 | 偶尔换维度 | 权力、信任、知识、道德、身份等轮换 |
| 付费点诚实性 | 任意截断 | 有变化但兑现不足 | 完成微弧后跨入明确、更高承诺阶段 |
| 原创与语言一致性 | 复刻或语言、视角失控 | 基本原创但表达模板化 | 原创表达具体，语言与视角适合本章；仍须分别接受正文检查 |

适用性与证据规则：

- 只评当前材料和功能能够支持的项目。未涉及付费边界时，“付费点诚实性”为 `N/A`；没有悬疑或解谜承诺时，“悬念公平性”为 `N/A`。单章不足以观察长线升级，也须说明范围，不能猜分。
- `N/A` 表示该项确实不适用，不等于 0 分或满分。适用但缺材料、尚未写正文或尚未核查的项目记 `not_reviewed`（未审），不能借 `N/A` 掩盖缺失工作。实际存在问题才按证据给低分。
- 不要求每章主角都作决断。人物能动性按本章承担行动功能的人物审查；如果本章功能是观察或消化余波，则审查其感知与反应，行动维度可以说明不适用，不强塞决断。
- 状态变化的数量、不可逆程度和爆点强弱不是质量排序。一个充分展开的理解变化，可以比同时改变五种资源更有价值。对手复杂度来自具体欲望、能力、限制、关系和自我解释，不要求善恶暧昧；明确恶意的对手也能复杂可信。
- 可报告“已评项目合计 / 已评项目最高可能分”，并同时列出 `N/A` 和未审项；12 项全有证据时满分才是 48。不按分数段自动批准、退回或要求重建。
- 版本之间只比较相同对象范围、相同有效维度和相同证据条件。适用项变化时逐项说明，不能把不同分母的总分或平均分当成质量提升。

设计证据只能证明设计质量。意图、计划、契约和作者说明不能代替正文：大纲通过不表示文风、连续性、情绪或章节质量已通过。结构分再高，也不能抵消下节的任何正文问题。

## 3. 章节证据检查

### 开场

- 行动章是否及时建立当前压力与行动方向？静场或余波章是否让读者进入具体处境、感受或关系？不固定为前 10–15% 必须完成同一组动作。
- 背景是否通过当前行动与后果进入？
- 独特职业、关系或规则是否参与事件？

### 中段

- 行动场景能否标出“行动 -> 反馈 -> 新行动”的因果链？内在处理是否有触发、感知和反应？
- 存在持续对抗时，阻碍是否会适应，而非静止等待主角？
- 每个主要场景是否推进选择，或充分展开人物理解、情感意义、关系与主题？
- 承诺了代价时，代价是否可观察并持续生效？
- 每个主要场景能否指出进入/离开状态变化或明确读者收益？
- 删除某场景后，是否既不损失因果、理解、信任、决定与情绪体验，也不损失具体的审美或主题价值？若是，删除或压缩；不能仅以“事件摘要不变”认定场景无用。

安静情绪场景不因缺少外部冲突而自动失败。若动作、沉默、共同物件或内在处理改变人物对事实的解释、关系信任、边界，或深化读者的情感与主题体验，它有价值；评分时引用实际展开的证据。情绪回返可以呈现犹疑、变化和余波，只有机械重复而不增加体验的内容才按注水处理。

### 兑现

- 本章承担兑现功能时，哪个旧问题获得答案、缩小范围或改变意义？其他章节是否完成了自身承诺的情绪或关系体验？
- 哪些前文细节在后文成为依据或获得新解释？
- 存在反转时，新信息是否改变人物理解或行动？

### 结尾

- 本章动作与意义是否完成后才结束？
- 存在章末危机时，它能否追溯到人物行为、既有压力或规则？
- 若为付费边界，是否依次完成阶段兑现、由答案触发的有代价选择、本章可见后果？
- 结尾提供何种完成感或余韵，又留下何种具体期待？期待也可以来自人物理解和关系意义，不必总是危机。
- 若结尾声称由关键选择引发，删除该选择后仍成立吗？若是，核查因果；不要把这个反事实测试强套给所有结尾。

## 4. 正文质量必须分别检查

先读实际正文，再逐项给 `pass`、`revise` 或 `not_reviewed`，每项附位置和短引文。`pass` 仅表示在已审范围内有充分支持；结构分不能覆盖任何一项 `revise`，未审项不能算通过。没有正文时以下各项全部未审。

若某项确实没有审查对象，例如该片段完全没有交流且不承担交流功能，可注明 `N/A` 及原因，不必硬加对白。仅因缺失前文或尚未执行检查，仍应标记未审。

| 项目 | 可执行检查 | 需要修订的证据 |
| --- | --- | --- |
| 语言 | 检查具体名词、动词、意象、句子节奏和信息负担是否服务场景；读出拗口、空泛或过度解释处 | 模板比喻、抽象结论替代体验、连续相同句式、指代不明；简洁或朴素本身不是缺点 |
| 人物声音 | 比较人物注意什么、如何命名、回避和回应；有对话时抽查去掉说话人标签后的区分依据 | 不同人物共享同一套口头禅、修辞和分析框架，职业或处境不影响表达；无对话时仍可检查感知声音，不硬加对白 |
| 视角 | 对照正文叙述约定与用户 POV 约束，逐句核对信息从何而来、推断是否冒充事实 | 限知叙述无标记读心、视角漂移、感知越界；明确采用全知叙述不自动算错 |
| 潜台词 | 抽查关键交流中欲望、话语、动作、沉默及误读的关系，判断直说或隐瞒是否符合此刻人物 | 所有人准确讲出主题和心理结论，动作只重复台词；坦率的告白或争执可以直说，不强求句句藏义 |
| 情绪可信度 | 对关键转变标出触发、人物解释、反应、行为与余波；检查信任、爱、恨或宽恕是否有相称依据 | 作者宣布“信任建立”，正文却只有一句道歉；转变跳过阻力，或人物在下一段无缘由恢复原状 |

将重点问题改在实际段落里，再复读相邻段落检查连贯性。不能以增加情绪标签、强烈形容词或解释性独白代替修复。

### 独立正文试读

关键章节、重要改稿以及用户要求质量诊断时执行一次；普通章节至少保留一次脱离设计说明的正文复读。试读必须读可阅读的正文，不能只审故事契约。

1. 准备试读包：实际章节、理解所需的相邻正文，以及必要的读者与语言约束。提供明示的形式约束（如严格限知 POV）时只列约束，不解释作者如何声称自己做到了。长篇材料分段须标明范围，不能把部分阅读报告为全文通读。
2. 不给试读者大纲、章节设计、作者意图、既有评分、预设问题清单或“此处已建立信任”等引导判断。外部 `reference_only` 素材也不进入试读包。
3. 有可用子代理时，给没有读过设计上下文的审者提供这个最小包；工具不能隔离上下文时，不声称独立。无可用独立审者时，由同一模型第二遍只按正文复读，并明确标注“自审第二遍，非独立试读”。
4. 审者记录具体位置和短引文：哪里困惑、想跳读或失去投入，哪里开始在意人物或想继续；每项说明理解和感受如何变化。先写读到的事实，再解释原因，不用作者计划补齐缺失台阶，也不为凑问题强报缺陷。
5. 上下文不足时报告“这里无法判断，需要哪段前文”，区分信息缺失与已证实错误。把重要问题落实到正文修订，再复读受影响段落及相邻上下文。

试读报告标明审者类型（独立模型试读／同模型自审／实际真人反馈）和阅读范围。模型推测的“想跳读”是模拟阅读反应，不能伪称真人反馈或实际留存、付费数据。连续性核查另行使用 canon；不要把作者事实表交给试读者替正文解释。

## 5. 连续性检查

建立并逐章更新：

- 角色：名字、称谓、年龄、外貌、职业、能力、伤病、所知信息；
- 关系：公开状态、私下承诺、信任依据、未解决冲突；
- 时间：日期、时刻、间隔、旅行时长、倒计时；
- 空间：人物位置、物件归属、入口出口；
- 规则：触发、限制、代价、例外及知情者；
- 悬念：开启、推进、承诺窗口、兑现和余波。

只将确认的 `project_canon` 作为事实依据，分别引用当前正文与既有事实的位置。`user_constraint` 用来核对约束，`reference_only` 不作为连续性证据。区分作者知道与视角人物知道；限知叙述不得直接使用人物不可能获得的信息，也不得为惊奇故意隐藏角色正在使用的已知事实。

缺少相邻章、时间标记或事实归属不明确时，记录待核项与所需材料，标为未审或局部审查，不硬判矛盾，不擅自补写 canon。仅在矛盾双方都有明确证据且不能合理解释时记连续性硬失败。

## 6. 重复度检查

回看最近三至五章，比较：

- 开场方式；
- 主要地点；
- 冲突类型；
- 主角策略；
- 情绪起点与终点；
- 章末牵引类型；
- 高频意象、动作、对话节奏和模板句。

重复是诊断信号，不是次数禁令。同一地点、意象或情绪可以形成递进与回响；检查每次是否改变含义或阅读体验。机械重复才需要调整，也可通过换主动者、换代价、换解释权或让旧策略失败来解决，不为求新强加情节。

## 7. 原创性检查

把作品降维为以下摘要：高概念、角色关系、关键规则、前三个重大选择、反转逻辑、代表场景和语言特征。

若这些内容能与某部具体作品逐项对应：

1. 保留抽象情绪承诺；
2. 更换人物目标与专业能力；
3. 重建限制、代价和社会后果；
4. 重写前三个重大选择的因果链；
5. 删除标志性措辞、场景顺序和关系标签；
6. 再次检查是否仍能逐场对应。

“换名字”“换时代”“换物种”不算原创重组。

## 8. 诊断输出模板

```markdown
# 诊断结论

一句话指出当前最影响阅读的实际问题或成立之处。注明对象、范围、章节功能、缺失材料和审查方式。

## 硬失败检查

列出适用项的结果与证据；不适用项说明原因，证据不足项标未审。

## 短质量结果表

| 项目 | pass / revise / not_reviewed | 位置、证据或缺失材料 |
| --- | --- | --- |
| 结构与章节功能 | … | … |
| 语言 | … | … |
| 人物声音 | … | … |
| 视角 | … | … |
| 潜台词 | … | … |
| 情绪可信度 | … | … |
| 连续性 | … | … |
| 原创性与用户边界 | … | … |

## 评分

需要量化诊断时，列出适用维度分数和证据、N/A 理由、未审项及有效分母。没有自动通过阈值。

## 正文试读

标明独立模型试读、非独立自审或真人反馈及阅读范围，报告困惑、跳读与投入位置和原文证据。未执行则直说，不编造审者。

## 优先修复

按影响排序，只列最多五项：
问题 -> 证据 -> 影响 -> 修复动作 -> 可在正文复核的效果

## 保留项

指出不可在改稿中损失的独特价值。

## 修改方案

给出可直接执行的场景或章节调整，不只给抽象建议。
```

## 9. 评测原则

- 同一提示词比较版本时，保持模型、参数、篇幅和输出要求一致；
- 客观断言必须引用输出证据，否则记失败；
- 文风、沉浸和模拟续读意愿采用上述试读协议，不伪装成确定事实或真人反馈；
- 先检查适用硬失败与未审项，再分别检查正文质量；总分不能替代这些判断；
- 不因为篇幅更长或措辞更夸张而判定更有吸引力；
- 不因为达到字数就判定完整；核对新增段落是否提供状态变化或读者收益，同时不得擅改用户确认的篇幅约束；
- 比较胜因应落在实际正文的语言、人物声音、视角、潜台词、情绪可信度，以及与章节功能相称的结构、兑现和阅读收益；不把爆点多、不可逆变化多等同于更好。
