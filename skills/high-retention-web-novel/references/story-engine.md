# 故事引擎与长线规划

- 日期：2026-07-23
- 执行者：Codex
- 适用：`project`、`outline`，以及需要重建根本设定的 `diagnose`

## 1. 故事承诺

先定义读者反复回来获取的体验。题材标签不是承诺；“狼人”只是元素，“一个因使用天赋而不断失去所爱之人记忆的验尸官，在职责与亲密之间选择”才包含可持续体验。

使用四层契约：

1. **事件承诺**：读者会持续看到哪类行动或难题？
2. **关系承诺**：哪段关系会因选择不断改变？
3. **情绪承诺**：读者主要获得渴望、复仇快感、恐惧、心痛、智性满足还是混合体验？
4. **意义承诺**：故事最终逼问人物相信什么、放弃什么或成为谁？

一句话高概念公式：

> 熟悉的情感欲望 × 非常规限制 × 不可逆代价 × 可再生冲突

内部工作句：

> 一个具有矛盾特质的主角，必须在明确期限前完成具体目标；但每次使用其最大优势，都会损害其最重视的关系、身份或信念，并逐步揭开一个会改变下一步选择的问题。

通过以下测试才扩写：

- **清晰**：谁、要什么、为什么难、失败失去什么都可被复述。
- **产能**：不临时添加巧合，也能列出至少十种不同冲突场景。
- **身份压力**：冲突迫使主角重新定义自己，而不仅威胁安全。
- **升级空间**：能轮换代价维度，而不是只让敌人变强。
- **题材专属性**：至少有一个代表场景只能由此人物与规则产生。

## 2. 五股故事力量

把以下力量写成能相互冲撞的因果系统：

| 力量 | 要回答的问题 | 失效征兆 |
| --- | --- | --- |
| 外部目标 | 主角现在必须完成什么可观察任务？ | 只想“变强”“获得幸福” |
| 关系困境 | 哪个人既是需要、阻碍又是镜子？ | 关系只靠误会拖延 |
| 内部误信 | 主角用什么错误规则保护自己？ | 内心创伤不影响选择 |
| 秘密/谜团 | 哪个答案会改变行动而非只满足好奇？ | 揭晓后剧情方向不变 |
| 持续施压 | 什么制度、期限、资源或对手会主动适应？ | 危机只在作者需要时出现 |

检查交互性：目标、关系、误信、秘密与压力应彼此改变选择，而不是五条互不相干的支线。例如外部胜利可能损害关系；使用优势可能强化误信；秘密答案可能改变对手策略。不按相互连接的数量凑结构。

## 3. 角色引擎

为每个核心人物记录：

```text
公开身份：
当前欲望：
深层需要：
最大恐惧：
错误信念：
可见能力：
能力限制：
脆弱点：
不愿跨越的底线：
隐藏事实：
对他人的筹码：
压力下的典型选择：
最终可能改变的信念：
```

人物深度来自互相牵制的事实，而不是堆叠悲惨经历。至少设计一组张力：能力与欲望冲突、爱与目标冲突、公开身份与秘密冲突、原则与生存冲突。

主角应在重要因果节点作出有意义的选择，暴露其价值取舍，并让后果进入后续故事；不能长期只被告知、被救或被伤害。非主角 POV、余波章与静场不必强塞主角决断，按人物理解、关系感受或其他实际阅读收益判断价值。

只为关键人物的重大变化规划“前态 -> 触发 -> 解释或抵抗 -> 选择行为 -> 后续证据”。计划说明将如何发生，正文证据才说明已经发生；后续验证未写到时保留待验证，不以一次觉醒宣告弧线完成。证据链的简短用法见 [prose-quality.md](prose-quality.md)。

## 4. 对手与对立力量

对手需要：自己的目标、成功条件、资源、限制、底线、对主角的正确判断与误判、收到反馈后的适应策略。

让对手具有可理解的决策逻辑，读者无需赞同。复杂性可以来自利益、原则、依恋或恐惧之间的冲突，不要求反派必有善恶两义。故事需要经营意图歧义时，才让证据支持不同解释，并随行动逐步压缩解释空间。

制度、环境、债务、疾病或世界规则也可以成为对立力量，但仍需可预测地响应行动。随机灾难不能代替适应性压力。

## 5. 关系引擎

每组关键关系记录：

```text
双方表面目标：
双方未说出口的需要：
权力不对称：
相互筹码：
共同风险：
不可触碰的边界：
当前信任依据：
当前怀疑依据：
下一次可能改变关系的选择：
```

关系变化要落到行为：谁交出信息、承担风险、尊重边界、利用弱点、公开站队或拒绝控制。避免用重复争吵或可由一句正常对话解决的误会维持张力。

信任升级、背叛或和解等重大节点沿用上述证据链，并分别记录双方的前态、解释与接受程度；不把一方示好自动写成双方亲密。规划中的转变与已写行为分开，实际通过质量检查后才更新关系状态。

恋爱张力至少包含欲望、价值冲突和资源互补。删除身份标签（Alpha、总裁、命定伴侣等）后，双方仍应因具体能力、目标和选择互相吸引或对抗。

## 6. 世界规则与能力代价

每条关键规则写清：触发条件、可观察效果、限制、代价、例外、社会后果和谁知道它。

好规则通过行动与后果被理解。先让人物依规则做选择，再补最低限度解释。能力代价必须：

- 在使用时可观察；
- 影响关系、判断、资源或下一步行动；
- 难以用休息或新道具轻易取消；
- 随重复使用改变人物策略，而不是成为装饰。

规则的例外必须提前留下证据。若例外只在主角必败时突然出现，它是救场，不是反转。

## 7. 弧线层级

### 全书层

确定起始误信、最终选择、核心关系终局和外部问题的解决方向。结局可以调整，但必须知道故事在证明什么，否则中段只能无限加敌人。

### 分卷/篇章层

每个篇章包含：

1. 新目标或新规则；
2. 对现有策略的压力测试；
3. 中点信息或关系重估；
4. 主角不可逆选择；
5. 阶段兑现；
6. 余波形成下一阶段目标。

篇章结束应在目标、规则、关系、舞台、身份、资源或时限上留下足以改变下一阶段的结果，不按变化项数凑升级。重要故事段落写完后须连读实际正文，检查转变是否成立、余波是否足够，以及中段有无重复旧困境；不能用章节表代替这次复读，详见 [prose-quality.md](prose-quality.md)。

### 章节层

为每章选择主要功能，其他线按需要触及，不强求每章固定推进两条线：

- 外部行动线
- 关系线
- 谜团/信息线
- 内在转变线

错开各线高潮，避免所有问题同时升级又同时停滞。

新书进入批量写作前，按 [prose-quality.md](prose-quality.md) 用已通过原创审查的设计建立短冲突/静场样本，或复用本书已批准正文，作为本书的文风基准。样本不设额外审批，不把练笔事实写入 canon；单章直接写作不展开这项作业。

## 8. 悬念与兑现台账

```text
loop_id：
问题：
层级：微 / 篇章 / 长线
开启章节：
读者已知：
角色已知：
预计兑现窗口：
中途升级：
兑现内容：
兑现后的余波：
状态：open / advanced / paid_off
```

微悬念应在当前或下一章解决；篇章悬念在局部弧内解决；长线悬念可跨卷，但必须定期获得实质推进。可靠模式是“回答旧问题，同时让答案产生一个更窄、更危险的新问题”。

反转要同时满足：前文事实可回看、原先误读合理、人物动机成立、答案改变后续选择。不要隐瞒视角人物已经知道且此刻自然会想到的信息。

## 9. 升级矩阵

轮换改变以下维度：

- 权力：谁能决定、命令或否决
- 信任：谁愿意交出什么风险
- 知识：新信息改变哪个假设
- 道德成本：成功要求跨越什么边界
- 身份：公开角色或自我定义怎样改变
- 资源：金钱、证据、盟友、能力或退路
- 时限：等待的代价如何增加
- 行动空间：哪些选择被关闭或新开启

连续两次升级若只扩大敌人数量或战力，重做一次升级。最强的变化常来自“同一个事实换了意义”或“成功关闭了旧退路”。

## 10. 原创重组

用“熟悉情绪承诺 + 陌生限制 + 独特后果”重组题材。先列出题材最常见的三种自动反应，再逐一改变因果：

- 保留读者渴望的情绪功能；
- 改变人物为何采取行动；
- 改变行动需要付出的代价；
- 改变胜利会伤害谁；
- 让独特职业、规则或关系真正参与解题。

先区分三类输入：`user_constraint` 是用户为新作品直接指定的设定、偏好、边界或已认可原创设计；`project_canon` 是用户明确要求继承的同一项目事实；外部素材默认为 `reference_only`。若输入含 `reference_only` 素材，先把素材隔离为“可借鉴的抽象功能”和“禁止继承的表达性特征”。可借鉴项只包括通用类型机制、情绪功能、压力类别、节奏诊断与非表达性约束；禁止把来源正文、角色关系表、特色场景、揭示内容、反转机制、重大选择顺序、转折链、逐章摘要、来源文件路径、标题、身份标签或私有比较记录带入后续规划和写作上下文。

从空白因果链建立新的主角目标、专业能力、关系利益、限制与代价，再独立设计前三个重大选择、揭示逻辑和代表场景。完成后做逐场对应检查：如果来源摘要与新方案只需替换名字、地点、职业、时代或物种便能互相映射，说明仍是复刻，退回高概念层重建。符合 `user_constraint` 且通过内部原创审查的设计才能交给章节写作；用户要求直接写时无需另行索要批准，只有重大改变已确认方向才确认。素材本身是否私密、原创或已有版权不改变隔离边界。
