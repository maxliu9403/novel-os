# 正文质量：文风、转变与整段复读

适用：新书批量写作前、重大人物或关系节点、深入修订、重要故事段落收束。这里的样本和记录属于写作依据，不新增运行时字段，也不要求每章交付表格。

## 1. 本书自己的文风基准

新书批量写正文前，基于已通过原创审查且符合用户已确认约束的设计，写一小段冲突场景和一小段静场，各以足够辨认声音为限；已有本书获批准的原创正文时，选取能体现这两种状态的短段复用。样本不是另一个创作阶段或审批关卡，不追加用户确认，不继承参考小说的表达，也不把练笔事件设为 canon。用户要求直接写一章时，依既有正文或当章设计直接写，在文风检查时校准即可，不另做样本作业。

从样本记下少量能指导改稿的特征：

- **POV 距离**：叙述贴近哪一层感知与思考，何时能拉远，哪些信息不能越界。
- **词汇与句法**：用词来自怎样的生活和职业经验，句子的长短、转折与停顿如何承载压力，而非固定字数比例。
- **比喻习惯**：人物会借哪类事物理解世界，哪些比喻与经验不符；不强迫每段出现比喻。
- **观察与说话策略**：不同角色先注意什么、忽略什么；交流中如何试探、回避、压迫、讨好或保护边界。

后续正文与基准比较时，检查辨识度、视角边界与角色差异；不要逐句套写。危险、亲密、疲惫和不同 POV 可以改变节奏。若修订产生了更准确的声音，更新基准即可，不为维持样本而损伤正文。

## 2. 重大变化的证据链

只追踪会影响人物弧或关键关系的节点，例如改信、背叛、信任升级、越过底线、重新承担责任。使用短链：

> 前态 → 触发 → 人物如何解释或抵抗 → 选择行为 → 后续证据

前态由已写行为或明确设定支持；触发须足以碰到该人物的需要与防御；解释可以通过判断、误读、辩解、沉默或试探显现，不要求一段自我剖白。选择行为证明当下变化，后续在机会、诱惑或压力下的行为证明它是否持续。宣言、一次顿悟、旁白说“他变了”都不足以独立完成链条。

规划时记“计划：前态／触发／预期行为／以后如何验证”。写后只把通过质量检查的实际片段记为“已写证据”，附章节与短引文或具体动作；后续验证尚未发生就保留为待验证，不提前宣告彻底成长或完全和解。允许反复与退步，但要能辨认新的压力、代价或自知，不能每几章重复同一次觉醒。

关系节点还要分别看双方的理解与接受程度：一方道歉不等于另一方信任，交出信息也不必等于亲密。重大转变缺证据时补其触发、抵抗或后续行为，而不是补解释字数。

## 3. 让关键节点发生在读者面前

重大选择、关系转折、核心揭示、关键胜负应写成场景。读者应能辨认人物在哪里、时间怎样推进、谁做了或说了什么、视角人物如何判断，以及这次响应如何逼出下一步。动作、对话与感知按节点需要取舍，不要求每场固定感官数或固定段数。

检查一个实用问题：删去“她终于明白”“两人逐渐信任”“争斗十分激烈”等总结后，读者还能从当下动作、语言和判断中经历那个变化吗？若不能，正文仍在复述大纲，应展开真正改变关系或局势的时刻。过渡路程、重复劳动、已经展示过的流程和时间跨度可以概述；无需把每件事都写成完整场景。

静场也须有具体体验。共同收拾桌面、对方留下的空位、说到一半改口，可以改变读者对一段关系的感受，即使人物当场没有新决定。保留这样的余波，压缩重复解释它“意味着什么”的段落。

## 4. 重要故事段落的整段复读

一个重要故事段落完成后——如关系阶段、调查阶段或篇章——连读其实际正文，而非只看大纲、摘要、状态表或逐章评分。结合段首已有事实，检查：

- 人物是否反复得出同一认识，却没有新的行为压力或变化证据；
- 关系是否从防备跳到信任、从伤害跳到和解，中间缺少抵抗、试探或选择；
- 胜利、失败或揭示之后是否留下身体、关系、资源和情绪的余波，让结果真正被经历；
- 中段是否只更换人物、地点或敌人，仍复用相同受辱、争吵、解法和情绪结果；
- 章节单看都能成立，连读却是否持续同速、同声、同样收尾，或过早覆盖值得停留的情绪。

重复地点、意象、台词与日常仪式可以显示变化；判断依据是它们在本次出现时的新情境、意义或情绪效果，不能为追求表面变化强换舞台。找出具体正文问题后，优先删并重复、补足关键场景和后果，再调语句节奏。新增内容必须有独立阅读收益，不能以“加强余波”为名注水。

只复读已提供或实际可读的正文；缺失部分不宣称通过。修订改变事实、选择或伏笔时，重新完成受影响的连续性、文风与质量检查，之后才更新已写证据和 canon。
