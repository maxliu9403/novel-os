# 章节工艺与阅读牵引

- 日期：2026-09-30
- 执行者：Codex
- 适用：`draft`、`continue`、`revise`，以及章节级 `diagnose`

## 1. 章节的工作

一章应提供能从正文指出的变化或阅读收益，而不只是容纳若干事件。`draft` 默认只使用这份精简章契约，不展开项目级故事引擎：

```text
视角与功能：由谁感知，本章主要让读者经历什么？
进入处境：怎样进入当前行动、关系或余波，让读者有所关切？
发展依据：人物行动与反馈，或事件怎样改变人物/读者的理解？
变化与收益：局势、人物、关系感受或信息发生什么实质变化？
结尾落点：本章意义如何完成，留下什么具体期待、后果或余韵？
```

若进入和离开时，局势、人物状态、读者理解及关系感受都无实质差异，也没有独特体验，则合并、删除或重建该章。

每个主要场景能指出变化及读者收益即可，不要求逐场填表。收益包括行动价值、答案、关系换义、人物理解或必要的情绪余波。非主角 POV、整理遗物、照顾伤口、共同吃饭或一段沉默，可以通过读者理解或关系感受的变化证明价值，不必当场导向主角的新决定。

## 2. 首章价值证明

首章需要完成一次小型但完整的价值证明。下面是行动型开篇的常用检查，不是所有章节的固定顺序：

1. **失衡**：从主角仍能作出有意义选择的最后一个稳定时刻切入。
2. **定向**：尽快让读者知道主角眼下要得到或避免什么。
3. **人物吸引点**：通过行动展示能力、脆弱、矛盾或边界。
4. **前提碰撞**：让高概念真正改变事件，不停留在简介。
5. **有代价的选择**：关键行动出自主角，两个选项都不免费。
6. **状态改变**：结尾展示选择后果，并形成具体下一步问题。

行动型首章可用“具体失衡、主角此刻在意的损失、当前行动方向”诊断开场是否空泛，不设统一百分比窗口。静场、其他 POV 或余波也能开篇，但应尽早提供人物立足点、值得在意的细节和可感知的张力；判断读者是否被带入故事，不强求同时交齐三项信息。

危险、情感不公、悖论、秘密、艰难选择或强烈欲望都能形成牵引。突出最值得在意的一项，避免未解释刺激过多而失去方向感；不按钩子数量判定质量。

## 3. 场景因果

行动场景可用以下循环检查因果：

> 局部目标 -> 阻碍适应 -> 压力增加 -> 退路缩小 -> 主动选择 -> 成功带代价或失败带信息 -> 新状态

行动场景应使计划、关系、假设、资源、底线或退路受到具体影响。静场和余波可以深化读者理解与关系感受；纯背景介绍、重复争吵和没有新意义的回忆应压缩。

执行删除测试：拿掉场景后，若因果路径、人物判断、关系信任、读者理解和后续决定都不变，且没有损失题材独有的体验，就删除或并入别处。不要把删除测试误用成“安静场景必须有事故”，也不要只因没有即时决定就删去必要的情绪余波。

推进主线的行动章应检查“人物行动 -> 反馈 -> 新行动”的因果链。其他 POV、余波与静场按本章功能检查；结尾需来自已建立的行动、关系或规则，不必每次由主角当章决断触发。

重大选择、关系转折、核心揭示与关键胜负必须在正文中展开为场景，让读者通过具体动作、对话和视角判断经历变化，并能辨认必要的空间与时间。过渡可以概述，关键节点不能只用扩写的大纲交代。深入写作与修订时按 [prose-quality.md](prose-quality.md) 检查场景证据。

## 4. 信息控制

让读者知道足够多，能预测风险；保留足够少，仍需要验证。区分：

- 角色知道、读者知道；
- 角色知道、读者暂不知道；
- 读者知道、角色不知道；
- 双方都不知道但已有可观察证据。

不得为了反转而藏起视角人物此刻自然会想到的关键事实。可以延迟解释，但先呈现事实、情绪或选择痕迹。

需要推理辨别的调查场景应检验解释，而不是靠旁白宣布答案；竞争假设与可证伪测试是有效手段，但不强求每章都安排两套假设。测试或新证据应改变判断，并让剩余问题更具体。

根据故事阶段安排答案与余波。连载中段的揭示应改变理解、选择或关系，避免用一场供述代替此前缺失的调查和铺垫。高潮与结尾可以集中回答多个问题，并给予充分的情绪收束；不为维持悬念而拖延已经该兑现的答案，也不要求每个答案都制造新代价。

## 5. 伏笔与反转

公平反转由三层组成：

1. **事实**：前文明确可见的物证、言行或规则；
2. **误读**：人物与读者为何会合理地赋予旧意义；
3. **新解释**：新信息如何同时解释旧细节并改变下一步行动。

重要反转必须有足以支持新解释的旧证据，证据的辨识度、相关性与误读合理性比数量重要。一处关键细节可能足够，多处无关细节也不能凑成铺垫。新角色、新监控、新匿名消息或突然能力只提供答案而无旧证据时，不构成公平反转。

反转之后要写人物处理冲击的选择，而不是立刻用下一个秘密覆盖它。

## 6. 人物与对话

人物说话同时追求表面目标并保护未说出口的需要。有效对话通常包含：

- 双方想从这次交流得到不同东西；
- 每人知道的信息和愿意承认的信息不同；
- 话语、动作、停顿或环境反馈彼此矛盾；
- 对话结束时权力、信任或计划改变。

不要用对话复述双方都知道的设定。把背景拆进争夺、纠正、隐瞒、试探和实际后果。

对手的复杂性可以来自目标、原则、依恋、恐惧和利益之间的冲突，以及压力下的取舍，不要求每名反派都有善恶两义。只有故事确实要经营意图歧义时，才铺设能支持不同解释的行为，再通过行动逐步压缩解释空间。

## 7. 情绪投资

抽象控诉不如具体共同生活。关系背叛、失去或欲望应落在：重复习惯、私人称呼、共同物件、身体记忆、曾被尊重的边界、对方独有的照顾方式，以及这些细节的新含义。

情绪变化也要有因果。关键人物与关系节点按“前态 -> 触发 -> 解释或抵抗 -> 选择行为 -> 后续证据”检查，不把计划、宣言或一次顿悟当成已经完成的成长。只追踪重大节点，具体记录见 [prose-quality.md](prose-quality.md)。不要用连续创伤取代人物行动，也不要让痛苦自动等于深度。

## 8. 感官与世界规则

选择能参与判断和行动的感官细节。好细节会：提供线索、显示职业能力、暴露关系、触发记忆、体现规则代价或在后文换义。

世界规则优先以“行动 -> 后果”呈现。每次能力使用都要让代价可观察，并改变判断、关系、资源或下一步策略。只说“这会很痛”而后续不受影响，等于没有代价。

## 9. 节奏控制

节奏不是一味加快，而是控制问题、选择和后果的间距：

- 高压段缩短反应时间，减少可用选项；
- 反应段让人物与读者经历、消化或重新解释事实，不必立即作新决定；
- 亲密段让关系感受更具体，可深化信任、理解、欲望，也可暴露边界或筹码；
- 说明段嵌入当前行动，只给理解选择所需的信息。

变化段落长度、句长、场景入口和退出方式。不要用固定“醒来—被羞辱—反击—陌生消息”的章法。连续章节若复用同一困境、解法和情绪结果，要检查是否新增了意义与代价；不要按地点或结尾类型计数强行轮换。有意义的重复地点、意象与生活仪式可以保留。

重要故事段落结束后，依 [prose-quality.md](prose-quality.md) 连读实际正文，检查重复觉醒、关系跳跃、胜利余波和中段复用旧困境。逐章合格不证明整段节奏成立。

## 10. 章末牵引

章末应完成本章动作和意义；若留下问题，问题要具体，风险要属于在意的人物，并来自已有故事。余波和静场也可以用关系感受、尚待消化的后果或余韵收束，不必额外制造危机。若用户要求自然付费点，再检查结尾是否连续完成“阶段兑现 -> 由答案触发的有代价选择 -> 本章内可见后果 -> 具体下一目标、时限或关系风险”；缺一项就只是普通章末或任意截断。

按本章功能选择，不必按表轮换：

- **决定**：主角主动跨过危险边界；
- **发现**：旧证据获得新解释；
- **代价**：胜利立即关闭一条退路；
- **关系位移**：信任、欲望或权力发生可见变化；
- **倒计时**：已知事件获得更短期限；
- **道德困境**：下一步成功要求越过边界；
- **带刺胜利**：目标完成，却产生更具体的新目标。

避免：在动作中句截断、刚要开门就结束、无铺垫陌生人来电、叙述者宣称“她不知道一切才刚开始”、重复使用昏迷或突袭。

## 11. 改稿顺序

按影响从大到小处理：

1. **因果**：转折是否源自人物选择和既有规则？
2. **能动性**：承担关键行动的人物是否作出有意义选择？静场是否因硬插行动而受损？
3. **兑现**：本章承诺的行动、理解、关系或情绪收益是否实际发生？
4. **关系**：冲突是否源于真实利益与价值，而非降智误会？
5. **连续性**：时间、称谓、位置、物证和规则是否一致？
6. **节奏**：能否删除既不推进也不增加理解、情绪或审美体验的段落？
7. **语言**：是否具体、自然、符合视角，且没有模板句？

不要先润色一个结构上无效的章节。重写后重新检查进入状态和离开状态。

章节必经顺序是：当章契约 -> 完整正文 -> 结构修订 -> 连续性检查 -> 文风检查 -> 质量量表与硬失败检查 -> 通过后更新 canon。快捷写作只能复用有证据的既有设计，不能把契约或大纲当作正文通过证据，也不能在修订前把计划事件写入状态。

用户确认的单章和全书篇幅是约束。若有效事件不足，深化阻碍适应、两难、证据换义、关系反馈或代价余波；不得用重复解释、同义情绪、无功能路程、回忆或对话凑字数，也不得自行更改目标篇幅来掩盖问题。

## 12. 成稿检查

- 开场是否让读者进入本章处境，辨认人物与值得在意之处？
- 行动章的反馈与选择是否可信？其他 POV、余波与静场是否完成其具体功能？
- 需要解题时，专业能力、特殊规则或独特关系是否实际参与？
- 本章承诺的答案、理解、关系感受或情绪收益是否能由正文举证？
- 关键转变是否有触发、解释或抵抗及行为证据，而非只靠宣言或摘要？
- 重大节点是否被读者经历，必要的代价与后果是否有余波？
- 结尾牵引或余韵是否由已建立的故事支撑？使用悬念时是否比“还有秘密”更具体？
- 每个主要场景能否引用状态变化或读者收益证据，而不强求新决定？
- 文风是否延续本书基准，且随场景情绪自然变化？
- 删除重复解释或无功能段落后，本章是否更强且仍满足用户确认的篇幅约束？
