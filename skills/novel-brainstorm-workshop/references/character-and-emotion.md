# 人物身份、心理与行为

## 身份锁定

为每位主要人物建立稳定 ID，并锁定姓名、允许的别名、年龄或年龄段、性别和代词、
职业、亲属与伴侣关系。名字有中英形式时记录对应表，避免将译名当成新人。
未指定性别或代词则标待定，不能为填表凭空确定；用户委托设计时可作为明确提案。
角色性别不决定其性格、职业、权力或道德。叙事中的他／她、he／she／they 与确认身份一致。

| 字段 | 作用 |
|---|---|
| `character_id`、姓名、别名 | 跨章节引用同一人；改名保留 ID |
| 身份、代词、年龄、职业 | 避免称谓、能力和时间线冲突 |
| 外在目标、内在需要 | 区分想得到什么和真正需要改变什么 |
| 欲望、恐惧、羞耻与依恋 | 解释什么事件最容易触动她／他 |
| 能力、资源、限制和底线 | 约束行动路径，让胜负有依据 |
| 性格、压力反应、做事风格 | 用可观察行为形成鲜明人格 |
| 说话方式与注意力 | 决定留意什么、怎样争取、隐瞒或拒绝 |
| 错误信念、矛盾与秘密 | 提供持续的内在冲突 |
| 成长轨迹与结果证据 | 以具体选择证明变化，而不只写“觉醒了” |

## 情绪改变行动

重要选择按这个因果检查：

**发生了什么 → 她／他如何理解 → 唤起什么需要或恐惧 → 情绪和身体反应 →
选择什么、压下什么 → 付出代价 → 下一次理解或行为如何不同。**

例如女儿发现父亲参加另一家庭的庆祝：她可以先保存视频而不对质，因为仍害怕最后一段
亲情彻底断裂；保存动作又让她第一次获得主动。这同时推进证据与成长，不需要旁白宣告
“她从此再也不软弱”。后来若再次心软，应有新触发和不同代价，不能每章重演同一犹豫。

家庭背叛、情感纠葛和成长题材尤其需要同时表现愤怒、依恋、自责、羞耻、松弛或希望。
不要只堆情绪词或长独白；用具体记忆、感官、潜台词和选择建立共鸣。人物可做不完美的
决定，但读者应理解原因。创伤不是增加苦难场面的借口，安静的恢复也能构成变化。

## 鲜明与立体

给主要人物一个可辨识的行为倾向，以及会使其违背惯常方式的压力条件。
“谨慎”可表现为先备份证据再联系律师；“傲慢”可表现为只修补曝光风险而不道歉。
同时留出矛盾：谨慎者可能为保护女儿冒险，傲慢者可能真切害怕失去崇拜。
这些矛盾要由经历与目标解释，不为反转临时增加性格。

配角有自己的需求、可提供的资源和拒绝的理由。对手有能力与限制，会从失败中调整，
不必强行洗白。每个人对同一事件可以有不同认识；信息获取必须有来源。
关系表记录权力、依赖、信任证据、隐瞒、边界和下一次可能改变关系的行为。

## 视角与检查

每场明确 POV 与知识边界；限知视角不直接报告另一个人未表达的真实想法。
内心描述应带有当前人物的职业知识、生活经验与语言习惯，不让所有人共用同一套独白。
在主要转折和卷／册边界检查：姓名代词、知情范围、能力、动机、关系状态和时间推进。
骨架只标记计划证据；真实正文出来后再核实其是否成立。
