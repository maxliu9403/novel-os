# 伏笔、钩子与持续回报

章节共同构成一条故事，而不是独立小剧场。目标是让读者持续获得新理解和情感回报，
同时期待下一步；不要求每章都惊天反转，也不把所有高潮压到结尾。

## 三种记录

**伏笔**是现在出现、将来获得意义的线索；**钩子**是使读者关心下一步的具体问题或后果；
**回报**是兑现已建立的期待。它们可以相关，但不是同义词。

| 伏笔字段 | 内容 |
|---|---|
| 稳定 ID | 如 `ch2:fs1`，修改章号后同步引用 |
| 首次埋设 | 章节、可见内容、视角人物 |
| 表面与真实含义 | 读者当下可理解什么，最终意味着什么 |
| 知情范围 | 谁知道真相，谁误读，依据是什么 |
| 强化／重新解释 | 哪些章节改变其可信度或意义 |
| 揭示边界 | 最早可揭示章节、所需前置条件 |
| 计划回收 | 在哪章通过什么选择、证据或行动兑现 |
| 改变与依赖 | 回收改变什么，依赖哪些先行事件 |

钩子记录 `hook_id`、提出章节、具体未完事项、承接章节、承接动作和预计兑现窗口。
回报记录对应承诺、兑现形式、受益或受损者、代价及新局面。计划中的兑现标为 planned；
正文出现后才以实际证据更新既有 `Payoff_Events` 状态。

## 每章连续合同

1. 章号、标题、卷或册、建议篇幅、POV、时间和地点。
2. 前章留下的外部后果与情绪状态。
3. 本章人物目标、阻力、心理理解与行动选择。
4. 获得的新信息、关系变化、能力体现或情感体验。
5. 代价、变化后的状态与仍未解决的问题。
6. 新埋、强化和回收的伏笔 ID。
7. 本章局部回报，以及结尾钩子的后续承接。

安静、观察或恢复章节可通过理解、关系和情绪改变发挥作用；用“删掉它后故事失去什么”
检查价值，而不是强加争吵。POV 切换仍需回应前文承诺，不能一直跳开迫切问题。

## 开篇与不断出现的新价值

前几章尽快建立可感知的冲突、人物需求与局部回报。可以是看穿谎言、保存证据、第一次
拒绝、能力被看见或关系出现裂缝；不能只有连续受辱、事故和重复宣告复仇。
不把固定的“三章模板”强加给所有题材。逐章写出价值差异和相互因果。

设计短线（下一章或近期）、中线（一个阶段）和长线（全书／系列）承诺。
开篇可揭露背叛存在，中段再查明规模、代价和可执行的反击；揭示后人物必须采取新行动。
每次局部胜利推动下一层困难，或迫使人物付出更有意义的代价。新困难应来自此前行动、
对手调整或已建立的现实约束，不能靠临时巧合续命。

轮换回报来源：证据、能力、身份与地位、关系、边界、道德勇气、谜题、公平反击、存活。
轮换是检查重复的办法，不是机械规定章节按类别轮流。相同物件或场景可重复出现，
前提是其意义改变。不能将同一争吵换个地点就称为新爽点。

## 公平揭示与结尾

读者回看应能发现线索；关键真相不能靠结尾突然引入的新角色或万能证据解决。
误导来自角色合理误读、信息缺口或可信伪装，不通过限知叙事故意隐瞒视角人物已知事实。
章末钩子的直接后果应得到及时承接，即使最终答案稍后才揭示；不要反复假死、假来电或
“门后究竟是谁”后无事发生。付费桥承接已建立的价值，不欺骗性中断或虚构承诺。

结局按篇幅留足升级、选择、代价、后果与余韵，不机械要求每本都占末 3–5 章。
主要冲突与人物情感承诺必须收束；最后一章可以平静而完整，不必再挖新坑。
单本分卷每卷有阶段回报并传递后果；系列每册有独立兑现，跨册未结问题应预先明确。
未经用户确认的“以后再写”不能成为主线不收尾的借口。

## 自检问题

- 前几章各自提供了什么价值？是否仍给中后段留下发展空间？
- 相邻章节是否由选择和后果相连，而不只是时间顺序？
- 伏笔引用和章号是否存在？揭示是否违背最早允许时点或人物知情范围？
- 本章兑现了什么，又改变了什么？是否只是重复羞辱、回忆或口号？
- 钩子是否有承接位置，回报是否建立在已有铺垫上？
- 每条核心承诺是否有结局证据？仅已确认的系列线可以标为 `intentional_open`。

这些是设计审读要求，不能声称程序已经保证任何模型写出的每章都有效。
