# 《孩子出生那天，我签了离婚协议》 Prompt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的女频婚姻逆袭设计转成可解析的 Novel OS 提示词，并通过一次自动化全书运行产出完整 Markdown 成书。

**Architecture:** 以独立中文提示词作为唯一创作输入，先通过 `prompt_intake` 校验结构化约束，再在独立项目目录中运行 `PipelineRunner`。运行使用 `approval=auto`、`quality_policy=evidence_v1`、5 次临时故障重试和每章 2 轮质量修复；所有章节通过后由流水线统一检查并编译 `book.md`。

**Tech Stack:** Python 3、Novel OS `core/orchestrator.py`、`prompt_intake`、`PipelineRunner`、Markdown、现有 Sub2API/OpenAI-compatible provider。

---

### Task 1: Create the executable novel prompt

**Files:**
- Create: `prompt/孩子出生那天，我签了离婚协议.md`
- Reference: `docs/superpowers/specs/2026-08-26-children-birth-divorce-novel-design.md`

- [ ] **Step 1: Write the complete prompt**

  Prompt must specify, in Chinese:
  - 36 chapters, each approximately 1000–1200 Chinese characters/words as supported by the intake schema, with small variation allowed.
  - Female-audience contemporary marriage reversal premise and the approved characters顾念、陈屿、安安.
  - First three chapters opening directly on solo prenatal checkups, confirmed affair evidence, financial transfer, gaslighting, and a medical-risk hook.
  - Production-day divorce, three-year mother-daughter survival period, no parental childcare support, daycare and multiple jobs.
  - Husband's three-year-later return after job loss and affair-partner breakup, escalating from pleading to attempted control through fatherhood.
  - Five-act structure, rotating anger/revenge beats, limited trigger-based flashbacks, continuity ledgers, and a final proactive divorce choice.
  - Per-chapter contract: conflict, emotional sting, protagonist choice, observable state change, and concrete ending hook.
  - Output protocol compatible with Architect, Scribe, Editor, Continuity Guardian, and Style Curator state blocks.

- [ ] **Step 2: Run whitespace and encoding checks**

  Run:

  ```bash
  git diff --check -- prompt/孩子出生那天，我签了离婚协议.md
  file prompt/孩子出生那天，我签了离婚协议.md
  ```

  Expected: no diff-check errors; `file` reports a UTF-8 Markdown text file.
