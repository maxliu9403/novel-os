# 作品目录、头脑风暴历史与单图修复

日期：2026-10-11。视觉修订：用户明确要求保持系统现有视觉，以下以本次修订为准。面向 Novel OS 创作者工作台，复用现有浅蓝紫、玻璃面板、圆角、无衬线字体及共享组件。

## 作品库：可浏览、可继续处理的作品目录

作品库以书为主角。统一 2:3 封面比例；尚无图片时用书名排版生成书衣占位。正式选中封面与候选预览明确区分，不通过展示候选图暗示作品已经完成交付。

每条书目呈现书名、作者、类型、字数与章节，并列显示正文和封面状态。次要任务标识收进详情，避免一张卡片被运行日志占据。作品主入口稳定为“打开作品”，封面入口根据下一步任务显示“设计封面”“查看进度”“确认封面”或“处理封面”。已有写作恢复和删除流程保留。

书衣、标题和卡片留白共享“打开作品”的原生链接，支持键盘及新标签页。独立封面入口、任务信息、恢复操作和管理菜单有独立点击区域，不随整卡跳转。

视觉复用系统 Scene quiet 浅蓝背景、glass-shell / glass-panel / glass-card、深蓝文字与淡紫强调、系统无衬线字体及胶囊按钮。宽屏保持工作区全宽；通过书名字级、封面和留白建立层次。不得另设纸色、绿灰或衬线出版风格。顶部提供搜索、正文状态和封面状态筛选；没有匹配项时可以直接清除筛选。窄屏保留阅读顺序和足够的触控区域。

## 状态：正文与封面分别表达

“正文写完”不代表封面已经选定。沿用真实正文状态，新增一个精简的封面状态维度，避免把封面的每个技术阶段暴露在作品库。

| 封面状态 | 含义 | 主要入口 |
| --- | --- | --- |
| 待设计 | 尚未形成可审阅候选 | 设计封面 |
| 处理中 | 后台确有规划、生成或修复任务运行 | 查看进度 |
| 待确认 | 已有候选或方案，需要人工检查与下一步选择 | 确认封面 |
| 需处理 | 生成／审核受阻、任务中断或存在待修复问题 | 处理封面 |
| 已选定 | 已明确选定正式封面 | 查看封面 |

具体失败原因留在工作室。列表状态来自服务端任务和保存结果，不凭图片是否存在判断完成。已有正式选中封面可以继续展示，同时提示更新批次的待处理情况；不会静默用新候选替换正式封面。

## 头脑风暴：独立历史入口

全局导航增加“头脑风暴”，与作品库并列。历史中心包含已启动作品的讨论，也包含待讨论、推导中、待确认、暂停和失败的讨论。提供书名搜索、更新时间、状态、当前版本、历史入口和继续操作；列表可以翻页加载全部历史。

打开历史只恢复状态，不自动调用模型。推导中的会话显示后台状态；可恢复的会话继续原阶段；已启动作品的讨论可查看并进入关联作品，不把它伪装成尚未启动的草稿。

状态与继续／查看讨论同处一行：桌面在条目右侧居中对齐，手机在摘要下方横向排列。页面使用全部可用工作区宽度，摘要本身保留适合阅读的行宽。

## 封面工作室：四个持久子页

工作室取消固定最大宽度，复用系统字体、颜色和胶囊按钮。使用“候选封面／美术方向／故事分析／费用”四个子页，同一时刻只展示一个内容面板。已有图片时默认展示候选；无图但已有方向时展示方向；全新作品从故事分析开始。显式选择写入 `?tab=`，刷新、直接链接和浏览器后退均可恢复。

子页切换保留面板挂载、所选分析及任务订阅，不重新分析或重发生成请求。长面板滚动时标签保持可达，切换后展示目标面板开头。方向、出图、修复任务继续在页头显示；隐藏故事分析页运行／异常时显示摘要入口，修复长方案在其他子页压缩为状态与查看入口。

“美术方向已生成”只在对应方向尚未批准时保留；确认完成任务的精确 `direction_id` 已批准后隐藏。运行、失败、失联或无关方向的批准不能隐藏该任务。已批准方案继续保存在美术方向子页，默认折叠供回查。批准成功可回候选页；如果作者在请求等待期间已经切换子页，则尊重后续选择。

## 基础设定：编辑与从头推导分离

1. 返回“基础设定”并点击修改，只进入可编辑表单。
2. 保存修改只保存设定，不启动模型。
3. 页面明确说明旧推导基于旧设定，询问是否从新设定重新推导。
4. 用户确认后归档旧过程，从新的上下文开始；旧候选、确认内容、模型线程及启动准备不能继续混入新推导。
5. 历史记录和已发生的费用保留；取消确认或刷新页面不会自动启动模型。已启动作品的来源不被回写。

该确认属于产品操作流程，目的是让作者决定是否放弃旧推导作为当前依据，并明确发起新一次模型调用。

## 单张封面修复：保留历史，按问题处理

每张需要处理的候选提供修复入口，绑定该候选的具体审核问题和版本。

- 仅审核失败：保留图片重新审核，不调用图片模型。
- 文字／排版问题：本入口保留原画并重新合成已批准布局，再审核；需要更换布局时沿用已有的排版提案与预览确认流程。
- 绘制问题：在明确的一次图片调用额度内，修复所选候选。
- 故事或构图方向问题：修订所选方案并重新检查来源、构图和执行配方，通过后才请求批准出图，不对同一错误方向反复抽图。

修复任务保存状态，刷新和切页后可以继续查看。新版本保留原图、审核记录与来源；其他候选、已选封面和交付包不被自动替换。需要图片调用时清楚展示只处理这一张、调用数量和执行确认；不自动无限重试。生成成功与质量通过依然分别显示。

最终实现、回归结果、部署版本与限制在本轮交付报告中记录；本设计文档不作为已完成验收的证明。
