## 审核路径

1. 点击“填入演示构想”，或输入自己的故事构想。
2. 依次选择主类型、故事背景、故事类型、情绪与风格；四组都至少选一项。
3. 最后一页点击“开始讨论”。自填组合只展示本地装配预览，不伪装模型理解。
4. 若想看完整首轮示例，使用演示构想，选择 **浪漫 → 家庭生活 → 家庭背叛＋第二次机会 → 虐心＋甜蜜**。三条总体路线支持单选和补充，提交只记录演示决定。其他组合也可通过明确的切换按钮打开这一固定示例。
5. 进入创作元素，选择“第二次机会”，查看 Markdown 编辑/预览，修改后保存，检查成功弹窗；尝试未保存离开、模板导入、检查格式、停用和删除说明。

没有组合方案管理，没有原先五层选择。前端保留简短的步骤与操作提示，详细创作知识在标签 MD 中维护。

## 原型与生产边界

本地 JS 校验只用于交互演示，不是生产 YAML/Markdown 安全解析器；生产规范见完整方案。任意 Markdown 是纯文本，预览转义 HTML，不能执行工具命令。

只演示快照与版本的视觉行为，没有服务端草稿、事务、幂等、SHA 签名或恢复能力。作者补充文字只记录，不触发下一轮推理。点击“查看预设示例”会明确切换示例构想和选择；未暗示能理解任意自填输入。

首次稿件质量、同组合的实际多样性、文学判断与模型耗时需要后续隔离实验。本轮未修改5174、真实任务、小说文件或生产资料库。
