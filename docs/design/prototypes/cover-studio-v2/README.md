## 四张样图如何表达故事

使用一个**虚构示例**《After Thirty Years, I Choose Me》，示例作者 Eleanor Hale。Evelyn 58 岁，在照顾家庭三十年后重新选择自己的生活；丈夫 Daniel 61 岁，成年女儿 Sophie 30 岁。示例不是任何正式小说的事实提取，未读取或修改正式作品骨架。

| 方向 | 故事表达 | 主要设计手段 |
| --- | --- | --- |
| 爱与边界 | 她走到自己人生的前景，家人的牵引仍在 | 三角人物关系、女主最大、统一家庭空间、深蓝与暖窗光 |
| 这一次，她先离席 | 熟悉的家庭秩序被一次选择改变 | 女主起身与家人留座的高低对照、视线聚焦、门外光线 |
| 牵挂在身后 | 她走向自己的生活，也仍然在乎家人 | 近景女主、中景亲人、连续空间和冷暖光线；不用头像分格 |
| 把未来还给自己 | 强调自我重启和情感牵连 | 明亮商业合成、清楚主配角层级、青绿与珊瑚色、金色标题 |

这组故意聚焦家庭关系，不代表所有小说都必须三人构图。第四张原提示要求半写实绘画，实际更像商业精修摄影，页面按实际画面描述；不能据此宣称美术媒介控制已解决。四图也不是新生产框架的真实验收结果。

标题与画稿分离，由 HTML/CSS 保序叠加 `After / Thirty Years, / I Choose / Me`，让关键词形成层级。真实导出时仍须验证字形、长书名、其他语言、字体许可及合成结果。

## 可体验的路径

1. 在两个 Tab 间切换。设计方案里的单方向编辑可保存到本地。
2. 点击「使用这张」直接选用，不要求理由，也不要求质量建议通过。
3. 点击「精修这张」，编辑要求；勾选“模拟精修失败”可看到失败恢复。再次重试会保留优化要求和构图保持项。
4. 点击「调整标题」，切换字体气质、颜色和大小，查看 120 × 180 缩略图。保存新排版不会替换已选封面；再次选用才生效。
5. 用右侧“演示状态”切换部分生成中、单张失败、整批失败。成功图片仍能选用；失败图片有单张重试入口。
6. 「重新生成 4 张」和「按此方案生成 4 张」会直接模拟异步进度，约 6.5 秒后完成；期间重复点击不创建第二个演示批次。刷新只恢复演示状态。
7. 查看费用、模型和版本历史。选择封面后可以查看交付清单，下载明确标注为演示的 JSON；不会生成假 ZIP。
8. 左下角「重置演示」清除本原型的本地状态。不会操作正式项目。

## 原型能力边界

本地状态使用独立 localStorage key `novel-os-cover-studio-design-v2`。没有模型请求、上传、认证或正式 API 连接；四张已有示例图片被用于状态演示。精修成功明确标注为“交互演示”，图像沿用原图，未假装完成新的图片编辑。费用为固定虚构示例，不是账户计费。

初始状态模拟“方向与四图已经生成”。首次完整骨架规划、服务端异步、真实图片编辑、持久版本历史、实际 ZIP、同脸保持、复杂标题引擎等仍属于规格中的待开发能力。演示仅保留最近排版和精修记录，不是完整历史存储实现。旧版、性能和跨题材视觉验收必须在生产实现阶段另做。

来源/偏好为只读示例。侧栏其他模块展示真实导航风格但不跳转正式应用。原型没有擅自更新正式配置、选择或作品内容。

## 本轮验证记录

浏览器实际操作验证：

- 方案/候选切换与直接选择；无需理由。
- 选择后保存另一个排版版本，交付预览保持原有颜色、字号与版本。
- 字体、颜色、字号即时预览；独立复核发现并修正 cqw 不随父字号缩放及颜色覆盖问题。
- 精修失败保留原图、提示和构图保持项；重试恢复后仍不自动选用。
- 四图失败后单张恢复，进度准确显示“1 张已完成 · 3 张生成失败”。
- 部分生成中可选成功图；刷新保留选用和任务演示状态。
- 宽屏四列与窄屏单列；检查实际 DOM 可用宽度 1441px / 341px 均无横向溢出，四图均加载为 1024px 原始宽度。
- JavaScript 语法检查通过；所有图标与图片在本地可读取。

截图用浏览器实际渲染保存；临时视口检查结束后恢复浏览器默认尺寸。这些验证证明原型交互可体验，不证明后端任务、费用、模型速度或真实成图质量。
