# 作品类型维护 · 交互设计稿

直接打开本目录 `index.html`。不需要安装依赖或启动 Novel OS 服务。

- 沿用项目锁定的浅蓝紫视觉、白色圆角面板、全宽布局。
- 左侧按维度分组，支持搜索/维度/状态筛选；右侧五个标签编辑。
- 共 26 份初始资料，包含新增的 21 个女频主题：婚姻背叛、出轨与双面生活、离婚重建、母女关系、职场成长等。每个主题可编辑具体故事机制；不是强制模板。
- 可保存草稿、保存并启用、复制、停用和恢复历史版本。
- 「预览创作选择」演示头脑风暴如何只选择启用版本。
- 「模型预览与版本」区分启用内容和未发送的草稿，提供易读视图和可展开的结构数据。
- 手机端先列表后编辑，键盘左右键可切换标签。

数据来自 `data.js`，修改保存至当前浏览器 `novelos.creative-types.design.v1`。新示例仅按稳定 ID 补入缺失项，保留本地已修改资料及版本；使用「重置演示」才恢复全部初始状态。文件浏览方式若禁止本地存储或 SHA-256，会明确提示；可改用本地静态 HTTP 预览。

**这是独立原型，不调用 API/模型，不修改任何真实小说、类型资料库或 H5 分类。** 发行分类只演示部分已知字典选项；生产页应读完整字典。结构完整性、版本冲突、请求预算、工作区权限等正式校验以设计文档为准，不能复用原型的简化校验作为服务端门。
