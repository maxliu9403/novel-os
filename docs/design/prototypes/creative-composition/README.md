# 创作元素与方案 · HTML 交互设计稿

日期：2026-11-02。状态：已被用户否定，仅保留历史。请审核 [新版四组标签原型](../tag-guided-workshop/index.html)。

沿用已锁定的作品库风格：浅蓝紫背景、单一白色圆角主面板、深蓝文字和紫色强调。桌面维护页和新书设定页在面板内部滚动，主要操作保持可见。

## 打开

直接用浏览器打开 `index.html`，或在本机启动静态预览：

```sh
python3 -m http.server 5198 --bind 127.0.0.1 --directory /Users/max/OpenSource/Novel-OS/docs/design/prototypes
```

访问 [设计稿](http://127.0.0.1:5198/creative-composition/index.html#library)。这是独立静态端口，不是 5174 应用。

## 建议审核路径

1. **创作元素**（`#library`）：查看五层资料，编辑写作指导、输出影响和适用分类。只有改动后才出现保存；保存成功显示弹窗。也可新增、复制和删除演示资料。
2. **组合方案**（`#recipes`）：查看三种组合，用其中一套进入新书设定；组合保留写作方向，不预设整本剧情。
3. **新书设定**（`#create`）：先选择 H5 主分类，再调整五层偏好。右侧摘要同步变化；也可将部分层交给模型推荐，保存常用组合。
4. **头脑风暴**（`#workshop`）：先选宏观路线，再选择开篇、中段和高潮方案。方案单选，支持补充意见、自拟方向或明确委托推荐方案；未作决定不能继续。故事全貌只显示已采用决定，未定部分保持待讨论。
5. **设定落实**（`#impact`）：查看每一层如何体现在骨架、场景和正文。此页明确使用独立固定示例，不冒充当前讨论的真实产出或质量结论。

可重点审核：五层名称是否清楚；维护页是否足够简洁；组合是否便于复用；宏观选择是否容易比较；从偏好到故事的过程是否看得懂。

## 演示范围与数据

- 全部状态只存在当前页面内存中。刷新或“重置演示”后恢复默认；不使用生产 API、模型、数据库或持久存储。
- 维持狼人、婚姻背叛、女性觉醒三套核心示例，另外五项仅为展示背景、文风等层次的原型扩展示例，不代表生产内置库扩容。
- `catalog.js` 来自仓库 `docs/examples/h5-import/novel-classification-catalog.json`，版本为 `novel-types.2026-10`；演示映射 ID 已对照本地字典验证。维护资料的适用分类与本书发行分类分别呈现。
- 模型建议、延迟和正文片段都是人工编写的演示数据。作者补充会保存并显示，但不会触发语义推理；任意自定义组合不意味着已有对应故事生成能力。
- 四轮只是可审核的演示路径，正式产品应按关键设计覆盖和作者决定判断是否可交付，不强制固定轮数。
- 示例说明传递方式，不能证明真实小说已经落实各层，也不能保证文学质量。生产验收仍需实际请求、骨架、正文和阅读反馈。
- 编辑、版本、删除和重新开始的确认用于体验设计；服务端版本冻结、幂等、旧资料迁移与任务恢复尚待正式实现。
