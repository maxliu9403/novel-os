# 整书路线 · 独立交互设计稿

状态：供 review，未接入产品。直接用浏览器打开本目录 `index.html` 即可；不需要启动服务器、构建、安装依赖或访问网络。

所有人物、六章资料摘要、路线与模型回应都是为本次界面设计编写的虚构样例，不是对实际作品的分析。样例人物均为成年人。题材目录同样是独立演示数据，`Mystery` 仅用于演示 Genre 切换，不声称现用库已启用该条目。生产实现必须读取真实启用目录与版本，不照抄原型 ID。

可以验证的交互：

1. 三条完整故事路线的情绪、看点和结局比较；推荐不自动选择。
2. 每条路线的四个详情页：情绪与看点、完整故事走向、全书悬念与兑现、原文与新设想。
3. 选定路线后调整读者方向、Genre、1–2 个 Tags，补充自己的意见。每条路线的编辑分别保留；恢复推荐不会删除意见。
4. “带入头脑风暴”展示交接预览，原文、模型设想、作者选择与作者意见分开呈现。不会创建讨论或调用模型。
5. 顶部状态选择器可查看旧版单路线、首次阅读未完成、新版本生成中、新版本失败；新版本失败不抹去上一版可用路线。
6. 键盘可操作原生按钮/表单；详情是原生 modal dialog，Escape 关闭，tab 采用方向键/Home/End；窄屏为纵向卡片。

本原型只保存页面内临时状态；刷新会重置。正式产品的持久化、幂等提交和恢复行为见后端设计方案。
