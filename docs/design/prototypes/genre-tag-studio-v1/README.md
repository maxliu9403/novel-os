## 建议审阅顺序

1. **新建小说**：构想与来源 → 一个主类型 → 该类型可用的多个标签 → 确认。至少一个标签，不要求每个检索分组都选。
2. **组合说明**：点标签右侧信息按钮；查看完整 Markdown。右侧解释选择会改变什么，“查看模型将读取的说明”显示组合后的样例输入。
3. **讨论示例**：默认 Romance＋背叛＋第二次机会＋独立自主，进入三种总体走向。单选后可附加开放意见，模拟一次提交。“查看标签的故事作用”显示作用于人物、行动、代价及阶段的规划意图。
4. **题材与标签**：切换 Genres/Tags、关联管理、编辑/预览 Markdown、复制、新建、停用、删除、完整文件下载。仅有修改时出现保存条，成功弹窗反馈。启用版本与已开始讨论的快照分开。
5. **参考书**：从第一步载入虚构示例资料，体验参考创作/原作重写及封面交接。overview 非必填，来源范围与新故事分开。
6. **H5 展示预览**：动态显示当前书确认的类型与标签，点击标签查看筛选入口意图。分类可以联合升级，不以旧静态字典限制新创作。

切换 Genre 会确认移除不适用的已选标签，其余保留。甜蜜与黑暗浪漫同时选择时让作者确定主次，而非简单禁止跨风格创作。其他任意组合仅展示已准备输入，不拿预写小说冒充模型输出。

## 内容与实现边界

- 真实研究编辑稿：Romance＋10 个 Tag，内嵌当时设计稿正文（固定原型快照）；唯一运行资料现位于[resources/novel-knowledge](../../../../resources/novel-knowledge/)；不加载原始小说全文。
- 悬疑和跨 Genre 关联是交互夹具，**没有声称完成悬疑语料研究**。
- 初始构想、目标读者、16章及每章1,100词是演示数据，不是新系统统一默认值。
- 三种故事走向和手机页 Synopsis 是固定虚构示例。任意输入不会触发真实推理；原型也不代表文学质量已验收。
- 来源“雨夜之后”及其封面为虚构 UI 占位。参考书目录导入仍是演示；封面页现在支持真实本地图片预览与浏览器缓存，但不上传、不调用模型或图片编辑。
- 保存、启用、删除只修改这个原型的浏览器本地数据。重置演示可还原；不修改正式资料库或书籍。
- 原型编译预览用于解释选择如何进入输入；正式实现需要服务端确定性编译、哈希与修订绑定、按阶段投影，不能把这份演示 JS 搬成生产编译器。
- H5 手机页是升级目标。实际 H5 仍待联合实现与合法/非法 ZIP 验收，不能据此宣称新标签已经能导入。
- 阅读评议 M3 的执行链退役属于后续应用开发，本轮没有删除运行中的接口或恢复历史评议。

## V1.1：参考图与封面工作室

入口：[封面原型](http://127.0.0.1:5201/prototypes/genre-tag-studio-v1/index.html#covers)。沿用同一面板与视觉风格。

- 不添加图片也能规划示例四方向；添加一张PNG/JPEG后可看原图、替换、移除。有效上传保存到浏览器IndexedDB，元数据和选择保存在localStorage；只供本机原型，不写正式媒体库。重置清除绑定，不删除既有缓存字节；关闭缓存或清站点数据后需重新选择图片。
- “试用示例图”采用旧封面原型的现成图片，不是本轮新生成。已人工观察并编写四项拆解，规划时显示建议，可选择借鉴项、修改偏好后重新规划。
- 新上传图片只预览、验证、准备输入，**不拿示例观察冒充新图分析**。任意非固定故事/组合也不会显示假生成方向。
- 原作重写来源交接有图自动走二创。独立入口不要求参考书；新作可借鉴视觉或选择原图二创。原型的来源封面是明确标注的演示素材替身，不是虚构书的真实封面。
- 四方向为SVG构图示意；候选页是旧项目的四张演示图片，明确标为非当前方向生成。可直接选用、打开单张精修输入；不调用模型或创建真实子图。
- 拆成cover-assets.js（本地文件验证/缓存）、cover-studio.js（原型交互）及cover-studio.css；app.js只接路由与上下文。生产编译器和任务调度另按设计合同实现，不把原型JS搬去充当后端。
- 11份知识Markdown新增可选“封面表达”，维护页可编辑查看；普通讨论输入排除该节，封面输入预览采用它。已有浏览器草稿不会被自动覆盖；使用“重置演示”可加载新版样例。

封面能力、边界与真实样图分析见[补充方案](../../genre-tag-studio-v1/cover-reference-design.md)。本次是设计审阅，不代表5174已经上线这些新增能力。
