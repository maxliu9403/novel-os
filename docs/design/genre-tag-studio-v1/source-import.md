# 参考小说导入与阅读合同

2026-11-05 · 已实现；原件不进入新书公开交付包。完整性指本地提供范围，不能推断未提供的付费章节或结局。

## 输入

```text
<title>__<book_id>/
  metadata.json
  synopsis.md
  chapters.json
  chapters/*.md
  cover.jpg          # PNG/JPEG，可选
  overview.md       # 可选，非权威
  reading_guide.md  # 可选，非权威
  raw/             # 可归档，不执行
```

支持ZIP和浏览器目录上传；客户端绝对路径不能作为服务端读取路径。保留metadata原键，chapters.json显式顺序与metadata列章需一致；缺文件、重复索引/路径、非法顺序、结构冲突会给出具体错误。章节目录中未列出的MD也纳入阅读，以“未列补充材料”标记，不能把公告当作完整结局。

Synopsis与全部所供章节为阅读输入；overview不是必填，也不替代原文。原始index只表示文件顺序，不擅自变成原书真实章号；叙事单元、跳章、预告和合集需要在分析中区分，不能把多个独立故事拼成同一人物关系。

已用当前200个真实Romance目录运行导入结构验证，200/200通过；证据在开发报告。这个程序校验本身不是语义阅读，先前的全量阅读研究单独保留。

## 无模型验证与存储

- 单ZIP≤128MiB、解压/目录总量≤256MiB、≤5000文件；单文本≤4MiB。
- 单张参考图≤12MiB，PNG/JPEG、单帧、单边64–16000px、总像素≤4000万；按实际解码类型校验，不信任扩展名。
- 校验UTF-8、逐文件/累计大小、ZIP声明与实际读取、路径归一化、压缩风险；拒绝绝对/越界路径、符号链接、重复规范化路径、文件/目录冲突、加密及特殊文件。不递归解压raw里的压缩包。
- 在有界读取期间计数，超限立即拒绝；不静默裁剪文本，不伪报已导入全部章节。
- 工作区独立 `source_books/<workspace>` 保存原件、角色、顺序、大小、SHA和source_manifest。来源ID由内容确定，相同内容重复导入复用，名称不决定身份。读取时再验来源SHA。
- source库与作品默认交付目录分离。外部文件中的命令只是资料，不成为工具权限或系统指令。

## 一次完整阅读，显式恢复

结构导入不调用模型。作者点击“读取资料”才启动，使用当前头脑风暴的模型/推理档位。准备时显示分组数及最大调用数；Synopsis和所有已供正文原文按连续区间覆盖，不重复携带metadata中的副本。

读取组按120000 UTF-8字节容量组合，超长段落带位置拆分；单回复≤96000字节，解析/综合请求有独立上限。N个读取组最多2N−1次正常调用：N次阅读加N−1次成对综合；能一组读完时只调一次。不是每章一次，不在每轮讨论重新阅读全书。

`SourceStudy` 保存来源、配置、系统/请求SHA及每次完整原始回复。成功步骤可复用；无效回复保留诊断，作者显式重试时只隔离无效检查点，不自动追加调用。取消/进程退出保存当前完成度；恢复只补未完成部分。模型或提示版本改变不能混用旧结果，点击“重新读取资料”会归档旧分析并重新开始。

状态包含pending、queued、running、failed、cancelled、interrupted、complete。页面刷新读取后台状态；心跳不证明远端正在思考。只有完整响应覆盖全部文件并完成综合后才能在创建中使用；没有分析结果不能跳过门槛。

分析固定区分：所供故事摘要、人物关系、叙事单元、机制与选择、开篇与钩子、简介写法、视觉建议、未决事实。视觉建议仅来自故事文本，不伪装成看过封面；真实图片分析在封面规划阶段完成。综合是有界派生分析，不等于原文逐字保留。

## 两种用途

| mode | 进入讨论的用途 |
|---|---|
| reference_creation | 学习机制、张力与表达方法；独立设计人物、因果、场景和结局，不换名复刻 |
| original_rewrite | 作者拥有改编权时重写；先确认保留与改变范围，未读后续仍未知 |

创建冻结source_id、analysis_sha256、source_sha256、分析、覆盖范围、模式和是否带图。后来重读不会修改已创建书籍的上下文。换模式或参考书走已有基础设定的明确重启流程。来源facts不会直接写入新书canon，只有作者采用的骨架成为正文权威。

原作重写的保留/改变边界在正常讨论中确认，不再新建大量必填表单。没有提供完结部分时，模型设计的结局必须标为新设计。

## 封面

来源封面可随创建带入工作室，也可取消。原作重写有图默认 `adaptation_reference`，参考创作默认 `visual_inspiration`；工作室仍可替换、移除或改变用法。项目拥有已验证图片副本，解除绑定不删来源原件。

独立新作可直接上传一张图。真实图片字节与故事/Genre/Tags一起进入一次视觉规划，后续走实际图像edit接口，不支持则明确失败，不能只传文件路径却声称已看图。精修使用候选自身原图。详见[封面合同](cover-prompt-contract.md)。
