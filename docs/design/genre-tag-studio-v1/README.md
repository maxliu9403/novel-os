# Genre / Tags、参考创作与封面：实现说明

2026-11-05 · 已完成代码与工程验收；未部署5174，未启动真实模型创作验收。用户批准除H5预览展示外的方案，并明确不要求保留历史创建流程。本说明取代早期审阅稿中的待定接口、旧知识迁移和额外placement表设计。

## 创作入口

沿用当前蓝白面板、深蓝按钮与紫色选择态。新建小说统一进入头脑风暴准备：

1. 输入构想，或导入参考小说。导入可选择“参考创作 / 原作重写”；需主动完成所提供来源的阅读分析。
2. 选择一个Genre，再选择1–20个关联Tags。可以查看每项怎样影响故事；更换Genre移除不兼容Tags前明确确认。
3. 设置语言、篇幅与每章目标，再开始讨论。已有方案单选、开放补充、故事地图、待定假设、阶段收敛与容量规划继续使用。

用户选择的是创作元素，模型负责组合成具体人物压力、选择、代价和回报。没有为每一种排列组合维护模板，也没有让作者填写逐章细节。服务端冻结选择和公开分类；模型不能悄悄撤下Tag或改发行ID。

## Markdown 知识

[唯一运行资料目录](../../../resources/novel-knowledge/)内置Romance＋10个Tag：Betrayal、Second Chance、Regret、Contract Marriage、Hidden Identity、Independent、CEO、Sweet Love、Comedy、Dark Romance。所有题材共用同一解析/编译链，不存在Romance专用执行器。

每条资料有六节：核心承诺、故事机制、发散空间、组合原则、场景与表达、简介与兑现；可选封面表达。条目说明为什么这种选择会改变故事，而不指定同一种主角、开篇或结局。作者可以新建Genre/Tag、导入/下载MD、保存草稿、启用、查看版本、停用或删除。保存按钮只在变化时出现，成功弹窗确认。

讨论、骨架、章卡、正文、既有编辑、作品简介、封面读取同一冻结选择的阶段投影。核心承诺在各阶段保留，研究附录不发送，预算超限明确拒绝而不截掉标签。资料库更新不影响在途书籍。完整格式与阶段表见 [Markdown合同](markdown-contract.md)。

文学兑现由已有故事地图/骨架/章卡与正常编辑承接，不新增逐Tag付费核查或另一套重复意图表。代码能证明资料确实送入正确阶段，不能保证模型的每个文学选择都精彩。

## 来源研究与复用

先前已完整阅读200本样本所提供的1743章节目录文件和200份官方Synopsis；覆盖凭证与批判性结论见 [研究目录](../../reports/2026-11-05-romance-study/README.md)。未读未提供付费后续，不把样本频率当付费转化率。先前Kit的固定章法、公告误判和标签歧义没有原样写入运行规则。

[Source Library](source-import.md)支持用户当前目录结构，overview非必填。导入先做代码验证；作者点击读取后，Synopsis与全部提供章节按容量分组，成功响应逐步保存，可暂停和显式恢复。来源分析供多书复用，不在每次讨论重读全文。所有文本已经发送不等于模型理解绝对正确，来源不确定项保留。

参考创作学习机制，独立设计人物与因果；原作重写在作者授权及确认保留范围内改写。只有新书采用的骨架成为canon，参考图、原书标签、分析推测不直接成为新书事实。可复用研究Skill见 [novel-corpus-study](../../../skills/novel-corpus-study/SKILL.md)。

## Synopsis

作品简介继续用现有 `publication_copy.spoiler_free_blurb`，与内部故事概要、章节摘要分开。Knowledge在publication阶段提供核心承诺＋简介与兑现，支持人物处境、具体关系、行动、代价和悬念；不罗列Tags或泄露最终谜底。它必须承诺本书已采用/已写出的内容，不从源Synopsis复制段落或创造未写出的情节。

## 封面

[封面合同](cover-prompt-contract.md)扩展现有单次完整骨架规划：没有图使用文本planner；有图一次视觉规划同时输出拆解、保留/转译/排除建议和四个方向。图片可独立上传，原作重写带图默认原图二创。实际图像字节进入规划和后续edit，不以路径或文字代替。

Genre/Tags、故事人物与关系、作者偏好共同决定海报表达；允许艺术化同框和象征，不要求每张图是书中某个瞬间。四候选、直接选用、单张精修、失败重试、本地排版和交付保持。精修以候选自身原图为准。

## 移除与交付

独立M3阅读评议的页面/API/worker/恢复逻辑已删除；不会偷偷转成另一套每章付费检查。正文阅读、写作中的编辑与连续性、结局检查保留，原有数据与费用未删除。旧复杂profile资源替换为唯一MD库，不维护旧编辑器兼容层。

H5预览展示未开发。导出已支持动态公开Genre/Tags：Manifest V4、EPUB、章节映射、作者、尺寸、SHA规则保持，分类升级独立v2。交付物由代码生成；写作提示词与来源全文不发布。H5仍需升级导入端，详见 [最终交接手册及真实ZIP](h5-taxonomy-handoff.md)。
