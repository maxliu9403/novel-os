# 狼人

## 读者期待

提供超出普通人类关系的力量、感知、归属和亲密张力，并让人物保有自主选择。

## 故事作用

从本书需要出发建立少量有效的能力、限制与族群规则。世界规则要能被行动检验，而不只是写在背景说明中。

## 发散方向

- 能力机制可从气味、感知、变形、治疗或群体联系中选择，不全量堆叠。
- 社会结构可以是紧密家族、分散社区、竞争族群或隐于都市的组织。
- 亲密联结可以是可拒绝的、需要经营的或代价不对称的，不预设天命覆盖个人意愿。

## 组合规则

与婚姻背叛结合，让狼人机制改变发现、利益与回应；与第二次机会结合，能力或联结不能自动替人物恢复信任。未选择的设定例子不变成本书事实。

## 分阶段指导

### 头脑风暴

提出因机制不同而产生不同故事的路线，避免默认Alpha救赎受辱女主。

### 骨架

规则、限制和代价进入关键转折，保持全书一致。

### 正文

通过感官、身体经验、行动和关系写出非人特征，避免反复解释规则。

### 评议

核对去掉狼人设定后因果是否仍原样成立；如是，需指出实际缺失。

## 避免套路

不要只加Alpha/Luna名号；不要用临时新增能力解围；不要以命定关系取消同意与选择。
