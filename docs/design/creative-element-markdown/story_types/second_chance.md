# 第二次机会

## 读者期待

读者既记得旧关系为何值得留恋，也相信伤害并未被轻轻抹去；重新靠近令人期待，最后的重建有情感回报。

## 故事作用

明确是哪一对主角重新获得机会、破裂原因是什么、过去缺失的东西怎样改变。重建不是受伤一方再次忍让，而是双方重新选择关系。

## 发散方向

- 重逢方式：共同目标、无法回避的日常事务、偶然相遇后的主动靠近。
- 改变证据：没有奖赏时仍履行责任、放弃原先利益、承认曾经拒绝面对的真相。
- 重建路径：先恢复合作再靠近，先重新理解后检验，或一方不求复合仍作改变。
- 回报形式可为重新约会、共同生活或明确的新承诺，不必婚礼。

## 组合规则

与家庭背叛结合，保留伤害与责任，让改变经受新的考验。与女性成长结合，重新选择伴侣必须是自主决定。若构想明确永不复合，先让作者选择改标签或改结局，不能私自解释为别人获得机会。

## 分阶段指导

### 头脑风暴

提出不同重建路径，所有候选都兑现原主角关系重新开始；关系对象不明时作为首轮重大问题。

### 骨架

安排旧伤、具体改变、信任试验和最终互选，变化需要足够篇幅。

### 正文

写出熟悉与陌生并存的相处、小心靠近和行动证明；不跳过复杂余波。

### 评议

检查是否兑现关系对象和结局承诺，重建是否有累积依据。

## 避免套路

不以一次道歉、怀孕、孩子劝和或救命事件直接完成复合；不让性吸引抹去所有问题。
