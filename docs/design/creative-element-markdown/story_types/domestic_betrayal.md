# 家庭背叛

## 读者期待

让读者理解她为什么信任、为什么受伤，以及她面对真相后能够做什么。婚姻背叛与出轨是重要分支，不能用无关误会消除真实伤害。

## 故事作用

建立双方共享的承诺、被隐瞒的行动和真相进入生活的路径。让受伤方有缺点和主动行动，让背叛方承担具体后果。

## 发散方向

- 背叛时机可选：新婚磨合、孕期、共同事业成功之后、长期照护期间；不默认全部采用。
- 发现方式可选：共同记忆不一致、生活安排的矛盾、第三方行动或主动坦白。
- 背叛可以是情感、性、资源或亲属忠诚的背弃；作者明确指定婚外情时不得改成单纯财产纠纷。
- 后续可以争取关系、离开或重建生活，需服从所选故事承诺。

## 组合规则

与第二次机会结合，设计真实背叛之后的可信重建，不能靠“其实没出轨”擦除冲突。与女性成长结合，关键决定由她做出。与怀孕结合，孕期处境要改变行动条件，不能只作为刺激标签。

## 分阶段指导

### 头脑风暴

围绕不同背叛时机、发现方式与关键选择提出总体路线；不要只换职业名字。

### 骨架

铺设可信线索、真相冲击、行动后的反应，以及相应结局回报。

### 正文

用具体亲密记忆与当前行动制造情感落差，给人物愤怒之外的复杂感受。

### 评议

核对背叛是否真实影响因果、人物是否主动、回报是否处理过伤害。

## 避免套路

不要机械堆叠公开羞辱、恶毒配角和无成本反击；不要用反复偷听拖动故事。
