# 浪漫

## 读者期待

让读者在吸引、相处和关键选择中相信这两个人值得相爱；不只关心他们是否在一起，也关心为什么只能是彼此。

## 故事作用

让两人的目标既相互吸引又产生真实摩擦。重要关系变化须通过共同经历、独特理解和付出表现；外部事件必须改变关系处境。

## 发散方向

- 吸引的起点：彼此误判后的发现、共同事业中的默契、旧日关系中被忽略的一面。
- 阻力的来源：不兼容的生活方向、关系中的不平等、过去伤害、相互竞争的责任。
- 关系的回报：学会共同生活、重建平等、主动选择彼此；不限定婚礼或生育。

## 组合规则

若同时选择第二次机会，以原有主角关系的重建为核心。若选择背叛，让浪漫回报建立在对伤害的承担上。不能自动将另一个更富有的人设置成解决一切的救星。

## 分阶段指导

### 头脑风暴

给出吸引、冲突与最终关系方向不同的方案；保持作者指定的关系对象。

### 骨架

安排靠近、受挫、重新理解与关键选择，标出关系变化的事件。

### 正文

写出具体相处的吸引力、双方不同的表达方式和心动后的行动。

### 评议

检查关系是否通过行动发展，回报是否由前文支持，而非只在结尾宣告相爱。

## 避免套路

不要只用外貌财富解释吸引；不要用误会拖满全书；不要让道歉或危险营救代替持续改变。
