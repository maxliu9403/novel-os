# 女性小说

## 读者期待

读者能够认出她生活中的压力与渴望，在复杂处境里看见她逐渐取得行动空间。

## 故事作用

先建立主人公想保留、想改变和不敢承认的东西。她的选择同时影响关系、身份和实际生活，别人不能代替她完成关键决定。

## 发散方向

- 成长可以发生在事业、照护、亲密关系、友谊或独处之中。
- 起点可为不愿再承担旧角色，也可为主动追求此前未有的生活。
- 结局可以保留亲密关系，也可以离开；自主不等于只能独身。

## 组合规则

结合第二次机会时，自主与重新选择伴侣应同时成立；与家庭生活结合时写出日常劳动和情感价值，避免把家人全部写成阻碍。

## 分阶段指导

### 头脑风暴

设计她真正想要的生活和代价不同的主要路线。

### 骨架

将她的认识变化绑定到行动、关系反应和持久后果。

### 正文

保留她矛盾、幽默、欲望和缺点，不让旁白替她宣布立场。

### 评议

以实际选择和后果判断成长，不以独白口号或离婚状态判断。

## 避免套路

避免所有女性相同的受辱逆袭；不要用获得新伴侣作为自主的唯一证据。
