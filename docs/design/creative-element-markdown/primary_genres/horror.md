# 恐怖

## 读者期待

让熟悉事物变得不可靠，使读者既害怕接近真相又想继续读。

## 故事作用

确定恐惧来自什么、人物为何难以退出、哪些信息尚不确定。危险需要边界和因果，恐惧不能仅靠暗房、天气与突然惊吓。

## 发散方向

- 恐惧来源：熟人行为失常、空间与记忆不一致、群体默契或未知生物。
- 呈现方式：逐步逼近、认知误差、可观察异常的重复变形。
- 代价：安全、信任、身份或某种珍贵关系的损失。

## 组合规则

若作者要求现实解释，不能自行加入鬼魂。与家庭背叛结合时，让亲密信任与危险相互影响；与甜蜜组合可以用温情建立将被威胁的关切。

## 分阶段指导

### 头脑风暴

提出不同的恐惧机制与求生/求真路径，明确现实或超自然是否待定。

### 骨架

安排威胁升级、认识变化和有铺垫的回应。

### 正文

通过感知、信息差和行为后果形成恐惧，保留人物可理解的行动。

### 评议

核对威胁规则、升级因果和回报；不能以惊吓次数判断质量。

## 避免套路

不要无限新增规则逃避解释，不要靠人物无故犯蠢推动危险。
