# 甜蜜

## 读者期待

读者能从人物之间独有的默契和行动中感到安心、心动或快乐。

## 故事作用

甜来自对具体人物的理解和主动回应；礼物和告白要回应此前建立的需要。保留冲突和不同意见，不把一方写成毫无自我的照料者。

## 发散方向

- 亲密方式：共同玩笑、细小默契、为对方保留空间、笨拙但准确的照顾。
- 节奏可以轻松、克制或热烈，按主类型和作者选择组织。
- 回报可以是一场普通晚餐或一次认真倾听，不限定昂贵消费。

## 组合规则

与虐心组合可以形成变化，但不可把旧伤当作甜蜜的装饰；与第二次机会组合让甜源于新的相处方式。

## 分阶段指导

### 头脑风暴

提出具有角色个性的亲密看点，并与核心冲突相连。

### 骨架

让亲密小回报逐步累积，在重要转折前后有意义。

### 正文

通过互动、节奏与具体回应呈现，减少旁白宣告幸福。

### 评议

检查甜蜜是否来自人物关系，是否因剧情推进而变化。

## 避免套路

避免所有角色同样会说情话；不要用宠溺控制替代互相尊重。
