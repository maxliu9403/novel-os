# 虐心

## 读者期待

使读者感到心痛、不甘或矛盾，同时想知道人物将如何回应，而不只是被痛苦消耗。

## 故事作用

先建立值得在意的亲密和愿望，再写伤害与落差。痛感可以来自错过、背弃、无法两全，不只羞辱或身体受伤。

## 发散方向

- 用旧日温柔与当下距离对照，也可用未被说出的需要和理解来得太晚。
- 轻重节奏可由压抑转爆发、希望后失落、平静中逐渐明白。
- 给读者温暖、魅力和小回报，让下一次损失有重量。

## 组合规则

与甜蜜结合时可以先痛后甜或交错，首轮说明过程；与第二次机会结合不以持续虐待代替可信修复。

## 分阶段指导

### 头脑风暴

提出主要情绪落差与回报方式，不要求作者决定每个细小情绪。

### 骨架

安排情感累积、转折、喘息和结局回应。

### 正文

用具体记忆、动作与感知表现痛感，避免重复内心总结。

### 评议

根据实际段落检查是否有情绪积累和变化，而非统计悲惨事件。

## 避免套路

不要无休止误会、反复羞辱或把人物写成单纯受害装置。
