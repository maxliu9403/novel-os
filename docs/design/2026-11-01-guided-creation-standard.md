# 新建小说：H5 题材、创作方向与三套资料标准

本补充落实总体方案 M1.1 的创建流程统一。视觉沿用浅蓝紫、白色圆角面板与深色主操作。

## 作者的流程

作品库「新建小说」直接进入「一起把故事想完整」，取消普通创建的前置表单。先选择 H5 题材，再选择可维护的创作方向，填写构想后开始讨论。不会因为选择标签就自动生成骨架。

| 层次 | 用户维护/选择 | 系统责任 |
| --- | --- | --- |
| 题材与发行分类 | 新书必选一个主类型；可选故事类型、情绪、背景、兼容题材、读者频道 | 只使用 H5 固定 ID 和组合规则，不接纳模型发明的分类 |
| 创作方向 | 狼人、婚姻背叛、女性觉醒及用户自建资料，可多选 | 冻结已启用的完整版本与 SHA；指导故事设计，不自动改变发行分类 |
| 本书故事方案 | 讨论不同走线、采纳/修改具体人物选择 | 保存方案与作者决定，显式交付骨架，贯通规划、正文与评议 |

狼人位于 H5「故事类型」，不是「主类型」。例如作者可选主类型奇幻、故事类型狼人，再选狼人规则与女性觉醒两份写作资料。主类型浪漫＋狼人也成立，其读者承诺不同，应在讨论中协调。资料映射仅表示适用题材，不等于本书选中全部映射 ID。

H5 `novel-types.2026-10` 的主类型 1、兼容题材 ≤2、故事类型 ≤3、情绪 ≤3、背景 ≤2；甜蜜浪漫与黑暗浪漫互斥。新 UI 使用 `creation_flow=h5_guided.v1`，后端缺少选择即拒绝保存。历史 API 客户端可继续未标记协议，旧讨论不会读取时迁移。新流程不可通过修改基础设定降回旧协议。

`publication_classification` 进入完整作者上下文。代码在候选保存、书名阶段及交付确认时，用作者 ID 重建唯一 `NOVEL_CLASSIFICATION_JSON`，派生分类身份/标签与章节范围，并同步骨架头部 Genre 展示字段；原始模型回复仍保存。已有 prompt intake → state → EPUB → publication package → ZIP 的确定性合同门继续校验。模型不能通过回复更换作者选定分类。分类变化需要编辑基础设定并确认重新推导，不靠模型判断字段是否正确。

## 维护页面

常用三页「定位与分类」「故事看点」「文风与检查」，另保留「模型预览与版本」。分类映射移至第一页，与创建表单读取同一字典。正文输入 15px，标签 14px，辅助说明 13–14px；保留手机单栏与固定保存区。

常用机制只需看：作用、触发、限制、选择、代价、回报。作用范围、例外、适用阶段、读者限制和多方向融合折叠编辑，原字段与保存能力不删。可在模型预览页核查不同阶段实际读取内容；不为预览调用模型。

## 一套可复用资料标准

资料不是故事成品。不要预写统一姓名、必然背叛者、固定拯救者或唯一结局。

1. 一句话定义独特的阅读体验，列 2–3 条具体承诺。
2. 列 2–3 个能改变因果的机制：触发 → 规则及边界 → 两难选择 → 持续代价 → 后续回报。标清可选机制，不能让所有机制必然同时出现。
3. 定义人物主动性、对抗者应对与关系变化，避免万能盟友和功能性配角。
4. 写可执行的文风偏好，允许静场、余波和不同节奏，不强制每章反转或机械感官数量。
5. 用问题检查逻辑、伏笔、代价和期待兑现；这些是审议工具，不是文学质量硬评分。
6. 关联现有 H5 题材，标明适用阶段；草稿不参与创作，启用后新讨论采用该版本。

三套完整机器资料见 `resources/creative-types/curated-v2.json`，沿用 `creative-type-profile.v1`，无新增私有发布字段。当前狼人 v3、婚姻背叛 v2、女性觉醒 v2；各自接续原版本号，不重写旧版本哈希。

| 资料 | 核心机制 | 可产生看点的选择 | 不固定的结局 |
| --- | --- | --- | --- |
| 狼人 | 能力与失控、群体归属与自治、可选伴侣牵引 | 救助外族会暴露本族的弱点；接受庇护意味着交出某项权利；被牵引的人未必值得信任 | 改变群体规则、代价明确地离开、重建合作；亲密关系由行动决定 |
| 婚姻背叛 | 日常裂缝与真相、共同利益中的行动、可选信任修复 | 一笔看似体贴的安排实际将风险转给主角；核实真相会暴露调查；接受眼前安稳会延续失衡 | 分离、有限合作、经过责任承担的重建，不能只凭一句道歉 |
| 女性觉醒 | 默认责任与边界、能力和资源建立、关系重新协商 | 一个具体机会与长期责任冲突；朋友愿意帮助但不愿代替承担；第一次自主行动不如想象顺利 | 有限却可持续的自主生活，不依赖暴富、变美或新的恋爱 |

表内为机制示意，不自动写进用户小说。三份资料均为创作参考，尚无真实读者效果验证。

## 同类型故事的多样性

新讨论面对开放构想时，比较 2–3 条有因果差异的走线。从「具体目标、权力关系、题材规则、对抗来源、行动代价、揭示路径、最终选择」至少改变三项，说明改变怎样影响主冲突和高潮。已由作者确认的事实保持不变；后续局部修改不强制重新产生多套方案。

例如同为狼人故事，可以分别围绕医师的救助伦理、流亡群体的生存协商、继承者对既有秩序的责任设计，而非全部落到拒绝伴侣与隐藏王族。人物职业只是起点，必须让知识、资源和义务改变事件发展。

本轮不加入额外自动模型调用或跨作品扫描。若作者提供参考旧作，要求明确比较核心机制与高潮；未提供其他作品时，不宣称全库去重或保证每本绝不相似。后续可另做作者可见的故事特征索引，真实质量仍需正文评议及读者反馈。

## 历史兼容

默认列表只展示三套精修资料。旧 55 项的原始资源文件不改，其他内置资料归档停用，历史版本仍可按 ID/version/SHA 读取。工作区已保存的用户记录优先于内置默认，不覆盖其草稿和启用内容。已有讨论保留完整快照，不热更新；明确采用新版才改变后续指导。旧项目、正文、封面和交付包均不自动重写。
