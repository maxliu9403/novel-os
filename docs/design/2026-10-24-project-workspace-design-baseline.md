# 作品工作台设计基准 v1.0

确认日期：2026-10-24（Asia/Shanghai）。

用户已认可当前设计稿的视觉与交互，并明确要求锁定。后续开发以本文件、当前原型及配套源码指纹为基准，落实数据与功能接入，不另行改版。此记录是设计确认，不代表功能已开发、部署或完成真实环境验收。

## 基准文件与适用范围

- 作品库：`prototypes/project-workspace-v2/library.html`
- 作品详情：`prototypes/project-workspace-v2/index.html`
- 样式：`prototypes/project-workspace-v2/styles.css`
- 交互：`app.js`、`library.js`、`skeleton.js`
- 文件指纹：`prototypes/project-workspace-v2/design-baseline.json`

范围为作品库、作品详情及相应阅读/交付入口。与现有封面工作室、导航共享系统视觉，不要求本次重做其他功能页面。原型中示例书的数据数量不成为产品限制，正式实现须适配任意作品。

## 锁定的视觉语言

- 沿用浅蓝紫背景、白色玻璃面板、深蓝正文、紫色强调和轻柔阴影。禁止替换为此前用户否定的米白绿灰、衬线出版风格或另一套视觉主题。
- 使用现有 Novel OS 标识和系统无衬线字体。保持当前标题、正文、辅助信息的层级，避免把重要内容缩成难读的小字。
- 主工作区充分利用页面宽度；保留合理边距、圆角容器、胶囊按钮和细边框。长内容通过标签切换、展开详情和局部滚动组织，不重新堆成单一长页。
- 色彩基准以原型 CSS 变量为准：正文 `#17213f`、次级正文 `#344467`、辅助文字 `#7885a6`、紫色强调 `#6867ea`、浅紫 `#efefff`。精确间距、圆角与响应式布局参考锁定的样式文件。
- 保留键盘操作、可见焦点、明确的加载/空数据/错误状态及窄屏可用性。可为可读性和可访问性修正局部实现，不借此替换整体视觉和信息架构。

## 锁定的页面与交互

| 区域 | 已确认行为 |
| --- | --- |
| 作品库 | 作品卡片可点击进入详情；卡片操作独立响应；支持搜索与状态筛选；提供“导出交付包”入口 |
| 详情顶部 | 保留封面、书名、作者、进度与主要操作；包含“阅读全文”“封面工作室”“导出交付包” |
| 一级标签 | 作品概览、章节、故事骨架、人物关系、费用与交付，共五项 |
| 章节 | 列表展示编号、标题、实际状态、字数和采用骨架简介；搜索/筛选；展开完整介绍；阅读与修改入口区分 |
| 故事骨架 | 左侧模块目录、右侧独立滚动内容；默认全书总览；所有模块、全部章节细纲可达；保留完整原文与下载 |
| 人物关系 | 人物列表与详情、明确关系表和来源依据；不恢复空头像卡片，不从共同出现自行推断关系 |
| 费用与交付 | 按头脑风暴/正文/封面分项展示人民币估算及token，总计与缺失状态清楚；集中放置交付格式与状态 |

移除详情页的素材集、设定库入口，不因此删除历史数据。原型默认打开章节标签用于评审；作品库卡片进入概览，正式页面可保留用户当前标签。

### 阅读与交付

“阅读全文”应进入只读全书阅读体验，包含完整目录、章节跳转、上一章/下一章、连续阅读；按需加载完整已生成正文，不用骨架介绍替代。未生成章节明示，编辑使用独立操作。阅读不能触发生成、修改或稿件自动提升；现有单章编辑器具有自动提升行为，不可直接当作只读阅读器使用。

作品库、详情和封面工作室使用同一交付包与就绪状态。就绪下载有效 `book-package.zip`；更新中、缺失或失效应说明原因并提供合适的处理入口，不能静默导出旧封面或把其他格式冒充ZIP。列表接口提供轻量状态，避免逐卡请求完整封面数据造成加载变慢。

## 已确认的 JSON 展示方案

默认展示业务含义，不把原始JSON作为主要内容。采用已有字段的确定性映射，不为页面展示增加LLM调用或重新生成骨架。

| 数据 | 默认呈现 |
| --- | --- |
| 创作规格 | 信息卡：预计章节、目标字数、语言、视角、单本/系列 |
| 分类与受众 | 中文标签、读者与市场说明 |
| 人物 | 列表与详情：身份、动机、困境、成长方向 |
| 关系 | 关系表：双方、关系、矛盾、预期变化 |
| 分章规划 | 列表＋展开：目标、事件、情绪变化、结尾钩子 |
| 秘密与伏笔 | 表格＋详情：内容、知情范围、埋设/揭示/回收计划 |
| 结局要求 | 人物归宿与待收束事项清单 |
| 封面交接 | 人物、核心冲突、场景和视觉限制等分组信息 |

第一版优先复用三类组件：信息卡、列表/表格＋展开详情、标签与状态文字。暂不增加复杂关系图或时间轴。每个模块保留“查看原始数据”；技术字段如ID、哈希和协议版本默认收起。

未适配字段放入“其他信息”，原文完整保留；空值显示“未注明”，不得补造。计划章节数、预期回收、设计检查与实际创作状态分开，不能把骨架承诺或检查结果渲染成真实执行完成。

## 实施边界

当前只确认设计。现有原型已有标签、目录、搜索、展开与来源浏览；JSON业务卡片、生产数据接入、只读全书阅读、跨页面交付包状态和作品库性能发布仍需开发与验收。原型演示按钮不能当作已完成的功能。

后续实现沿用此基准，允许必要的数据接线、状态补全、响应式/可访问性和缺陷修复；不擅自替换主题、重排五个主标签或恢复已删除模块。新的功能沿用当前组件语言；用户后续明确修改设计时再记录新版本。

正式小说完整原文快照仍位于被Git忽略的 `assets/private/`，不包含在公开设计源码指纹中。此次锁定不创建Git提交、不推送、不重启或部署服务。
