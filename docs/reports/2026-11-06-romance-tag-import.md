## 内容建议：仅供作者判断，未写入提示词

以下基于本轮查看的具体 Tag 原文，不是对35份内容及其原始语料研究的完整文学审计。

1. **主 Tag 与辅助 Tag 分工。** 多份文档各有「前 10 章强制节拍」，组合时可能要求同一章走不同路线。可考虑让主 Tag 决定主线推进，辅助 Tag 改变角色关系、压力或表达，并明确结局优先级，例如 Tragedy 与其他 HE 倾向标签并用时先确认结局。当前未新增优先级、强制限制选择数量或更改任何节拍。
2. **把必写场景的功能与地点分开。** Betrayal、Affair 的离婚登记处、宴会、法庭/发布会很具体，容易在不同作品中重复。可考虑保留「决裂止损、公开反转、最终清算」这类戏剧功能，让地点、筹码和行动随故事变化；尤其不要将十章清算模板强行重复为长篇结构。当前按原文导入，未做替换。
3. **区分原创与原故事推演。** 文件的「不复制原文人名/地名」自检与原故事推演保留已有角色的要求可能发生冲突。可考虑将这条限定为原创/改编模式，续推模式则保留已知人物和事实、发展新的剧情。当前没有擅自加入模式例外。

格式与后续维护说明见 [Tag Markdown 格式](../design/genre-tag-studio-v1/tag-prompt-markdown.md)。
