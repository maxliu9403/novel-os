# 作品工作台 v2 实施与验收

按已确认的 `docs/design/2026-10-24-project-workspace-design-baseline.md` 实施，沿用浅蓝紫、白色面板、深蓝无衬线文字和圆角交互。本轮只改变工作台展示、阅读和交付入口，不改变小说生成策略。

## 已实现

- 作品库批量读取 artifact 元数据，避免每章重新扫描完整版本日志；列表附带轻量交付状态，不逐卡请求封面详情。
- 作品卡片进入概览，并提供独立 ZIP 操作。详情为作品概览、章节、故事骨架、人物关系、费用与交付五个标签；任务状态可折叠查看，暂停/恢复入口保留。
- 章节列表接入采用骨架简介与来源、实际状态与字数、搜索/筛选/展开。正文阅读与编辑入口区分。
- 骨架模块目录、独立滚动内容、完整原文与下载。JSON 映射为字段卡、表格、标签；其他字段和技术信息可展开，原始数据完整保留。页面转换不调用 LLM。
- 人物与明确关系取采用骨架；兼容 Character Ledger/Core、H3 档案、JSON 及历史编号档案。不从同场出现推断关系。17 部现有作品均有可展示人物。
- 新 `/projects/:id/read` 只读阅读器：目录、章节切换、上一/下一章、连续阅读、完整保存正文与版本标签。不会 ingest、写状态、自动 promotion 或调用模型。canonical 定稿存在即权威，明确清空不回退历史旧稿，损坏报错不静默替换。
- 统一 ZIP 操作：就绪时校验响应类型和 ZIP 文件头再下载；失效可显式本地更新；缺失进入交付；正在重建不可重复提交。无写锁的遗留 pending 显示中断且可恢复。
- 源数据与阅读文件采用只读文件描述符、逐级禁止符号链接；缓存随依赖变化失效。移除素材集/设定库入口，历史数据未删除。

## 部署与数据

2026-10-24 本机 Docker Compose 5174 已部署，前后端 healthy。切换前后均检查 17 作品、7 会话，无活动任务；没有启动模型、重试小说或出图。前后 29065 个作品文件 SHA-256 完全一致，无新增或删除。

本机验收文件位于 `/private/tmp/novelos-workspace-v2-*`，包括测试日志、界面截图、数据库备份、作品文件哈希和下载 ZIP。旧运行应用源码备份为 `/private/tmp/novelos-workspace-v2-backend-before`，旧静态前端为 `/private/tmp/novelos-workspace-v2-frontend-before`。原运行镜像已无法按其容器记录的 ID 重新打 tag，因此不声称存在本轮精确镜像回滚标签；已保留对应实际运行源/静态文件。

工作树保留原有修改，未 Git 提交或推送。历史骨架格式不统一，部分旧作品的模块分组较粗，完整源文件始终可查看和下载；人物关系仅展示可明确提取的关系。
