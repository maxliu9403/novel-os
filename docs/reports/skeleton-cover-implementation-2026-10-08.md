## 已实现的链路

1. **精确定位骨架**：通过已授权项目 ID 读取 `outputs/input/prompt.md`；讨论阶段区分当前稿、有效确认稿和明确指定的历史存档。路径由后端解析，不按书名或修改时间猜测。采用新解析器只读复核了清单中的 20 个项目，20 个均找到非空骨架，hash 与原清单一致，最大文件 214,124 字节。
2. **不可变全文来源**：保存原始 UTF-8 bytes、清单、内容 hash、来源 owner 和 snapshot 身份。prepared 资格与已批准封面的内容身份分开；仅会话 revision 改变不会撤销相同内容的封面批准。支持跟随当前来源及固定历史快照，两者都要校验批准的内容。
3. **全文理解与可追溯证据**：全部原文分段提取，超长证据分层整合；再逐段对照原文核查全局理解，并核查跨段关系与因果。原文引用由程序校验唯一匹配、字节范围和 hash。持久化进度、失败记录、暂停及同 ID 恢复，只有完整且验证通过的结果可复用缓存。缓存包含 provider、模型、端点身份、推理配置及分析契约。
4. **电影宣传海报方向**：v10 方向分别描述同场景冲突和多层宣传组合。每个方向有故事时点、人物行动与反应、图层关系、可见异常、未解问题、刻意保留的答案及剧透边界。结构校验后再进行独立语义审核；原作没有支持的同场人物、假因果、空泛问题和重复组合会被拒绝。
5. **批准准确的绘图指令**：v15 编译保留功能钩子和核心事实；超限报错，不从尾部截掉故事信息。批准前保存 recipe 与 hash，生成使用已经批准的文本，不随编译器升级重新编译。新字段按存在性序列化，旧方向 hash 保持兼容。
6. **无字画稿与标题分离**：新方案支持 composed 排版，使用本地允许字体并绑定字体文件 hash，保存原画、标题布局和最终封面的身份。字体不可用、缺字或越过批准范围时不静默替换。Dockerfile 已补字体依赖，部署后已在容器中验证三个允许字体及对应中英文字形。
7. **独立看图与费用控制**：先只看无字画稿，后将已保存的观察与原作、方案及成图核对。评分协议明确处理嵌套格式、字段冲突、缺失分数和文字污染。故事失败回到新方向审批，评估故障只复评已有图片；标题可用已保存原画和批准布局本地重合成，仍超范围则要求修改并重新审核，不消耗图片额度。当前图像供应商的修复能力按原方案整图重绘说明，不冒充局部编辑。默认额外图片额度为 0，可在审核时明确允许每张额外 1 次；同一批准不能反复申请整批生成。耗尽额度不会阻止查看和合法选定已有图片。
8. **实际成图比较**：本地比较同批画稿的相同 bytes 和近似图像，保存结果供人工比较，不因此自动花费出图额度。界面分开展示独立观察、故事判断、工艺判断、未知项、原画／成图／历史版本。人工接受未达建议标准的候选时记录理由。
9. **Web、CLI 与讨论阶段**：项目工作台和讨论工作台共用来源、分析、方向和批准逻辑。CLI 增加 inspect-source、analyze、plan、approve，生成和重试不能跳过新方向的绑定校验。讨论封面可显式导入正式项目，完整保留原始来源、分析、批准及尝试历史；不自动激活交付封面，不复制可花费预算。

## 使用入口

项目封面工作台：`/projects/<project_id>/covers`。

讨论骨架预览中的“基于骨架设计封面”：`/workshop/<完整 session_id>/covers`。有骨架即可分析，不需要提前启动正文任务。

界面流程：核对来源 → 分析完整骨架 → 查看人物／冲突／原文依据 → 创建方向 → 审核方向与来源 → 生成 → 比较与人工选定。已有旧封面继续保留，旧记录不会被补标为“已完成全文分析”。

2026-10-08 用户试用后的界面简化：项目工作台自动读取本项目 `outputs/input/prompt.md`，移除来源下拉、讨论 ID 和存档版本输入；更新策略固定为生成前校验当前来源，不再展示策略下拉。保留原文预览、重新读取、完整分析及已有分析查看。讨论专用入口自动读取该讨论当前稿。此前的其他来源与导入能力保留在后端／CLI，项目页面不再提供这些选择。首次操作引导同步补上“分析完整骨架”。相关 3 个测试文件共 21 项通过，ESLint、TypeScript／Vite 构建通过；此次界面发布仅更新 frontend。

如果骨架依赖独立的人物设计或章纲文件，须显式声明相对项目／讨论目录的路径。例如：

````markdown
```COVER_SOURCE_DEPENDENCIES
{
  "characters": "design/characters.md",
  "chapter_outline": "design/chapter-outline.md"
}
```
````

缺失附件、路径越界或符号链接不会被自动回退替代。普通 Markdown 链接不自动当作必需附件，也不会自动读取外部 URL。
