# 封面工作室 v2 实施与验收

2026-10-16。依据[已批准产品规格](../design/2026-10-16-cover-studio-product-spec.md)实施。本文的真实验收数据使用独立虚构小说，不代表正式作品已重新出图。

## 已实现的流程

作品封面入口默认使用 `skeleton_poster`：完整骨架及声明附件冻结后，一次联合规划故事核心、关键人物关系、四个美术方向与标题布局。最多一次可执行格式更正；移除旧版逐段分析、证据账本及语义往返审核作为默认前置步骤。超预算会在模型调用前明确失败，不截断骨架、不偷偷更换模型。

`poster_staging` 允许宣传同框、关系姿态、象征合成、摄影或插画。保留年龄、身份、核心关系、世界和作者禁项；不要求静止画面证明某章的全部因果，也不要求每本固定出现几个人。

主界面沿用系统蓝紫色、深蓝按钮、白色卡片和全宽布局，仅保留“设计方案／候选封面”两个主标签。来源、历史、费用分别进入抽屉。方向可本地修改人物、构图和配色；修改生成新版本，旧执行描述不会反过来覆盖新构图。

“按此方案生成”保存精确方案批准和幂等请求。四图串行调用、逐张保存并立即可选；完整图无需理由、无需等审核或其余图片。后台最多一次组合建议，只提供可操作意见；失败不改图片状态，不自动补图或重评。

原图精修直接绑定真实参考图 SHA 与用户要求，产生一个新版本。兄弟候选、原图及正式选图保持。失败可显式重试；已有画稿时只续本地排版，不重复支付图片调用。未确认的远端结果显示中断，不自动重放。

标题使用真实服务器渲染器，预览与导出相同：保序换行、逐行字体／大小／颜色、区域、间距、描边、阴影和渐变。字体按文件 SHA 固定，缺字与出界提前检查。旧无字画稿可继续排版；原生内嵌文字的历史图不会被伪装成可无损去字。旧固定配方不自动添加新效果。

## 状态、计价和交付

- 刷新和切页读取持久任务；相同请求及合并别名返回原任务。前端只清理本次匹配的请求编号，防止迟到响应误清新请求。
- 进度区区分后台状态、上游事件和实际内容事件，不将心跳解释成模型一直在思考。
- 请求模型与服务实际报告模型分开；未知模型或 token 不填成零。新请求冻结模型单价和汇率，费用按规划、出图、精修、重试、建议及历史未分类请求统计，均标为人民币估算。
- 选择后同步真实 EPUB 内嵌图片、封面文件、ZIP 清单和 H5 SHA；正文与分类内容不改变。选图成功和交付成功分别记录。若 EPUB／ZIP 重建失败，选择保持，旧 ZIP 留存但禁止冒充当前版本下载；独立重建不调用模型。
- 原 V11 分析、方案批准、图片与费用不迁移或改写，旧链接仍能查看。头脑风暴内部的旧封面入口保留原协议；本次替换的是作品封面工作室。

## 真实模型验收

采用当前配置的原生 Codex 文本与图片渠道，所有测试资料位于隔离目录。没有向模型发送正式小说资料，也没有改变正式骨架或正式选图。

家庭样本实际生成 4/4 张；首张 95.34 秒可用，整批 369.06 秒，未等待逐张文本审核。一次原图精修另用约 101.88 秒，成功返回 child 图片；父图和三个保留兄弟的 SHA 不变。

这些是小型完整测试骨架的一轮观测，不能推导所有长骨架的固定耗时或成功率。八题材验证了真实规划；实际四图及精修来自同一本家庭样本，不能称八题材的成图质量都已验收。第四案规划为写实插画，实际视觉更接近精修摄影，媒介遵循仍受图片模型影响。首轮默认标题也暴露了部分低对比／字级偏小问题，随后补齐规划内标题配方和本地效果；不得把测试替身通过当作审美保证。
