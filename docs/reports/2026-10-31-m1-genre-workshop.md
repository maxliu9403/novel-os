# M1：题材机制与主动讨论

日期：2026-10-31。分支：`codex/novel-quality-optimization`，基于 M0 的 `fd1e8cf` 开发。

状态：工程实现与本地验证完成，未部署、未推送；没有真实模型调用。真实设计样例与读者效果验收仍待开展，不能据此宣称小说质量或留存已提高。

## 改动与使用方式

原有头脑风暴已有主动提出故事走线的提示，分类也已传入上下文。本次补充的是可复用的题材机制资料、版本绑定和可追溯的方案决定，不是首次给模型添加分类标签。

新讨论按所选类型加载通用原则及适用的专用资料。首批为狼人、当代家庭情感、悬疑/惊悚，包含阅读期待、细分方向、触发条件、作用范围、限制、例外、代价、选择、回报、失败模式和混合类型注意事项。其余类型保留原始选择及已有分类设计要求，并明确标记通用指导。资料不是固定桥段，不强制命定羁绊、每章反转或某种结局。

每轮正常回复之外，可保存精简方案卡：具体事件与选择、取舍、推荐理由、不同类型在本书中的作用、本书机制、未确认假设、尚需取舍事项和下一步建议。移除题材机制后选择/高潮是否仍然成立，是设计诊断，不是新增文学分数或硬门。

用户可以继续自然语言交流，也可在方案卡保存“采用、不采用、暂缓、修改”。按钮只保存本地决定，不调用模型；下一次讨论或显式生成骨架才使用这些意见。模型不能写入作者决定，方案 ID 由服务端产生，按钮记录绑定当前会话、版本、原始方案和作者文本。自然语言选择不依赖按钮确认，其原文完整保留在对话中；不会通过关键词猜测“继续”表示全部同意，也不把模型对自然语言的解释伪装成结构化作者操作。

讨论仍然默认 `discuss`；只有独立完整骨架操作使用 `deliver`。无最低轮数、无新增逐项审批页。已保存的创作决定变化后，旧骨架可回看，但不能靠返回 `ready=true, prompt_md=null` 再次宣称它已更新。

## 实现边界

| 部分 | 实现 |
| --- | --- |
| `resources/genre-design/v1.json` | 自有题材资料，与发布分类字典分离；没有复制第三方代码或数据 |
| `core/genre_design.py` | 使用现有分类精确别名匹配；保留全部原始选择，不推断主次，不从包含否定表达的故事原文自动添加题材 |
| `api/workshop_design.py` | 创作策略/资料快照、方案记录、明确作者决定、讨论/交付各自的提示规则 |
| `api/workshop.py` | 创建、新一轮、重新推导及响应保存接入；新增版本锁保护的 `POST /api/workshop/sessions/{id}/decisions` |
| `api/workshop_delivery.py` | 原始作者上下文与交付检查点绑定包含创作资料和决定 |
| `web/src/components/WorkshopDesign.tsx` | 下一步建议、折叠方案/机制、资料覆盖说明及决定回看，沿用现有视觉样式 |

决定请求示例：

```json
{
  "revision": 2,
  "proposal_id": "r1:p1",
  "status": "revised",
  "note": "盟友改为姐姐，保留失去族群庇护的代价。"
}
```

返回更新后的会话，不创建后台推理任务。过期版本或正在运行的会话返回 409；不存在的方案、空修改意见或不支持的状态不落盘。再次改变决定保留原始历史，当前采用投影使用每个方案的最后一次操作；后续自然语言明确修改仍以作者最新意见为准。

## 失败、成本和兼容

- 方案卡是非阻断附属记录。缺失、超限、不合法或试图伪造作者决定时，保留正常讨论回复，显示卡片未完整返回；不会因此追加模型调用或截断原始讨论。
- 每轮最多 3 个方案、每方案最多 3 个机制，附属结构最多 48,000 UTF-8 字节。模型被要求只记录新提案/变化，一般每方案一个机制、每字段一句话。这些限制仅适用于附属结构，不截断作者原文或已保存回复。
- 会话保存完整资源及提示策略快照和 SHA-256；资料升级不会改变暂停任务的策略。旧会话读取/恢复不自动迁移，在明确提交新一轮时才采用 M1。
- 保存基础设定仍不调用模型。作者确认从头推导时，旧方案和决定随旧讨论归档，新上下文重新构建；历史及费用记录保留。
- 所有方案历史留在会话。讨论请求只重复携带最新方案卡及当前采用项，不逐轮重发所有旧机制；交付请求不附带历史待定方案卡。完整原始对话仍可用，避免遗漏自然语言意见。被采用但随后拒绝的方案从当前采用投影移除。
- 分阶段交付只附带简短交付规则，不插入讨论卡 JSON schema。它仍使用原有阶段协议和 17 节骨架，不另造发布合同。
- 未修改分类 ID、分类上限、分类字典、H5 ZIP/EPUB 格式或 M0 强制门。该创作记录是讨论资料，不是 H5 发布字段。

离线测量：单狼人资料约 4.4 KB，家庭约 4.0 KB，悬疑约 3.7 KB，三组混合约 8.5 KB；讨论规则约 3.4 KB，交付规则约 1.0 KB。这只是新增上下文字节，不是实际 token、延迟或费用测量。
