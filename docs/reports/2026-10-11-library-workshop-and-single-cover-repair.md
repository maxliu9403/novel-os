# 作品库、头脑风暴历史与单张封面修复

日期：2026-10-11。设计依据：`frontend-design`；故障排查：`diagnosing-bugs`。具体界面与交互方案见 [设计文档](../design/2026-10-11-library-workshop-and-cover-repair.md)。

## 交付内容

1. **作品库**：纸色出版目录、2:3 封面、无图时的书名排版书衣，突出书名、作者、正文进度、封面进度和下一步操作。搜索和正文／封面筛选保留在 URL；任务标识收进详情，保留原作品、恢复及删除入口。
2. **封面状态**：待设计、处理中、待确认、需处理、已选定。根据真正运行任务、方向可用性、候选审核及正式选择投影；过期或被拒方向不再显示待批准。单张修复也参与状态。已有正式封面继续预览，新批次待处理不会静默替换它。
3. **头脑风暴历史**：导航新增独立 `/workshop`，包含所有有效历史讨论及已启动作品的讨论。支持搜索、状态筛选、分页、状态刷新、指定讨论深链接和关联作品入口。打开历史恢复已保存阶段，不自动调用模型。
4. **基础设定编辑**：编辑按钮明确为 `type=button`；保存只保存。修改后持久显示重新推导确认，刷新／切页不会自动触发。确认后归档旧过程，清空旧对话、骨架、命名、准备信息并从新设定开始；旧候选的回退路径也由新轮 revision 边界隔离。历史内容、费用和 Token 保留。运行中及已启动作品不允许重启，重复确认不重复派发。
5. **单张修复**：绑定原候选、版本、来源与审核问题。故事／构图与绘制修复只修订选中方向，完整验证与独立审核后提供可审阅方案；用户单独确认新增 **1 次**图片调用。其他方向、图片、原正式选择均保留。新增批次记录不可变父批和保留槽位来源，选择与交付时重新验证。任务可恢复，响应丢失只查询，不自动重放。

## 边界与质量说明

- 单图生成是重新绘制该候选的整张图片；没有声称实现局部像素编辑。
- 排版类单图入口只用原画重新合成**已批准布局**，再审核；变更布局继续使用已有的排版提案、预览、精确批准流程。已有排版修订／导入记录的候选沿用其原有流程，避免覆盖旧审批来源。
- 重新合成及仅审核为 **0 次新增图片调用**，质量审核仍可能产生文本／视觉模型费用。
- 完成修复不等于质量通过；仍被阻断时继续显示真实问题。新候选不自动成为正式交付封面。
- 本轮使用替身验证模型与图片调用。没有重绘现有小说，也没有新增真实模型费用；无法据离线测试宣称任何真实小说修复后必然达标。
