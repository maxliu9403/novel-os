# 整书路线前端实现与隔离验收

## 实现范围

资料库和新建头脑风暴共用 `SourceRoutes`，连接新整书路线 API。卡片比较具体第一幕、读者期待、重要场面、结局与差异；详情完整展示情绪的场面、选择、代价、关系变化和后续兑现，以及全书因果、人物关系、悬念、来源与新增假设。此阶段不生成逐章细纲。

题材推荐与作者实际选择分开，允许修改 Genre、Tags 和频道；已有明确选择不会被推荐覆盖。路线选择独立于修改范围，允许反馈后修订指定方案或保留已有方案追加。历史版本和旧版单路线分析均可查看，新版本不会自动成为作者选择。

两入口通过持久 operation ID 直接交接并打开首轮讨论。新建表单的标题、原始构想与其他已填字段逐字保留，模型路线不会填进作者构想。尚未提交的分析意见继续作为草稿；已提交反馈和交接意见明确带入。网络响应中断重试复用操作标识，成功完成后结束当前创建草稿，后续明确新建得到新标识。

反馈、每条路线的题材和交接意见按来源、模式与创建草稿隔离保存。恢复使用原运行记录；中断或未知请求状态不展示技术对账表，也不宣称必然能取回未知结果。旧分析、历史讨论和运行中的创作任务继续使用原协议。新旧来源摘要兼容，关联讨论和作品不要求新路线提供旧版 analysis hash。

## 验证方式

使用真实 React 页面、隔离临时 Vite 端口 19137 和 Playwright 浏览器，全部 `/api` 请求由固定样例拦截；不连接生产资料、真实模型或任务。样例中多条路线复用文学文本以检验布局与操作，不能用这些样例证明路线文学质量或差异化水平。

浏览器检查包括：资料库选线、Genre/Tags 编辑、补充修订、追加两条后显示四条方案、历史版本回看、旧版分析展开；切换来源和模式不会串联反馈草稿；新建头脑风暴原位导入后保留带换行与空白的作者原话，实际交接请求包含修改后的题材和交接意见，随后展示已创建讨论。新路线来源 `analysis_sha256: null` 的关联列表也实际打开验证。

桌面 1440×1050、手机 390×844 均检查；手机无横向页面溢出，路线详情可纵向滚动，关闭内层详情不会关闭外层新建讨论。根据观察减少资料库手机布局的重复内边距。临时浏览器和 19137 服务均已关闭，5174 和现有服务未操作。
