# 头脑风暴方案选择与发送内容回显

状态：已于2026-11-07 00:56按用户后续授权部署至5174。此前遵守“有任务运行，只修改不要重启”；部署保留真实讨论，不发起模型调用。见[部署记录](2026-11-07-workshop-ui-deployment.md)。

## 现场证据

讨论 `52482a7186d04e3eab635764d3b4c26e` 的第4版输入回复保存了两条有效结构化 proposals；guidance 为 unavailable，story_state.pending 为空。页面只能展示 Markdown 说明，无法呈现选择控件。方案与分组/地图的耦合使有效内容丢失了交互能力。

用户补充完整保存在 messages[5]，共3,019字符。新工作台把全部对话放在“讨论记录”中；默认“本轮决定”只显示助手的最后回复。提交成功还会立即清空输入框，并等待轮询更新会话，所以出现内容消失的感觉。

## 修复

- `workshop_story` 统一构建本轮问题：优先使用有效分组；分组不可用但已有2–3条经过校验的结构化方案时，提供单选问题。保持原方案内容与ID，不从自由文本猜测可执行选项，不补造地图或生成就绪状态，也不追加模型调用。
- 选择后仍通过既有原子请求提交方案与补充；未选不默认采用推荐项。显式自定、委托、提问、换一组逻辑保留。
- 对已有未回答的记录，共享会话入口提供相同的确定性投影，GET本身不落盘；下一次显式操作正常保存。作者已用文字回答、任务运行中、已删除/启动创作、待重启、已有决定或未决问题时不重开旧选项。
- 结构化方案有效时，不再因缺少 next_focus 而丢弃整个方案记录。明确返回无分组的有效 guidance 不强行转换为问题。
- 新增独立提交回执组件，默认页保留最近一组用户输入，包括重试前的长补充；可滚动阅读全文或进入完整讨论记录。成功受理后立即显示本地回执，轮询到持久化消息后使用保存记录，不重复插入消息。请求失败保留草稿，不谎报发送成功。
- 等待模型时明确显示正在推演，将旧回复标为“上一轮设计说明”并折叠。
