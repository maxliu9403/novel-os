## 使用入口

设置 → 服务连接 → 添加连接 → **Gemini 网关（OpenAI 格式）**。

- 当前 Docker 中的 Novel OS 可填写 `http://host.docker.internal:8083/v1`。宿主直接调用对应 `http://127.0.0.1:8083/v1`。
- Token 填独立的 API 密钥框；现有私密存储复用，不写入 URL，不回传明文。
- 保存连接后拉取模型列表；设置文本路由并保存，然后进行“测试响应”和“测试长上下文”。
- 原生 Google Gemini 仍为独立连接，避免把两个协议混用。已有小说、模型选择和推理档位未修改。
- 若浏览器仍显示旧设置，强制刷新，或打开 `/settings?build=gemini-openai-20261106`。新入口已返回 `Cache-Control: no-cache, must-revalidate`。

## 协议实现

`core/gemini_gateway.py` 封装此网关的差异，沿用 LLMClient、路由、用量与现有后台测试任务，不新建第二套业务流程。

| 能力 | 行为 |
| --- | --- |
| 模型目录 | Bearer Token 调用 `GET /v1/models`，稳定排序，排除 image/music/video/canvas 媒体工具，保留 thinking 完整 ID |
| 生成 | `POST /v1/chat/completions`，system/user 原文完整传入，流式 SSE，申请 usage |
| 思考档位 | 通过完整模型 ID，例如 `gemini-4-argon-thinking-medium`、`gemini-4-argon-thinking`；不发送无效 reasoning_effort |
| 输出额度 | 网关忽略 max_tokens，界面禁用并说明；本地仍有任务时限和异常输出大小保护，不声称可限制远端费用 |
| 图片理解 | 同一适配器传入 PNG/JPEG/WebP image_url；不把媒体工具当作小说文本模型，不新增图片生成服务 |
| 完成标准 | 只接受非空、正常 stop 的完整流；残缺、错误、过滤、截断不作为成功结果；应用客户端不自动重试 |
| 进度 | 正文及思考活动分别计为可观察信号，思考文本不拼入正文；首段正文独立计时 |
| 模型身份 | 单独显示网关返回型号，但标明实际型号尚未核验，不能把回显当作上游身份凭证 |
| 用量 | 网关估算，不是官方计费 token；该网关 reasoning 单列，规范化后计入总输出以防遗漏，费用仍为配置单价估算 |

源码依据：网关 `internal/app/server.go`、`sse.go`、`messages.go`、`strict_model.go`。其 strict_model 默认关闭；开启时也只能在有上游身份信号时拒绝已知降级。本轮没有读取私密配置来推断实际开关，也没有替用户开启。

## 大上下文结论

**目前不适合把这条网关直接设为所有小说阶段的默认连接。协议兼容不代表具有官方模型的全部上下文容量。**

1. 网关 `internal/app/config.go:108` 默认内联阈值为 **128,000 UTF-8 字节**，不是 token。
2. `internal/app/context_file.go` 中的历史实验注释记录：附件中偏移 157,833 可读，163,371 不可读，总量约 160 KB 后存在读取缺失。它是项目作者记录的经验值，**不是本轮实测，也不是稳定保证**。
3. 当前实际代码超过阈值后上传整个 prompt 为 `message.txt`，再对缩短后的指令检查长度；没有对原始附件施加上述 160 KB 上限。因此注释所说“超限明确报错”并未完整落实到这个路径。多个附件也不能据此宣称扩大可读总量。
4. 本地 19 本已保存骨架仅按文件大小统计：最小 12,812 字节，中位数 132,125，最大 215,672；**11 本单骨架就超过 120,000 字节**，还没加系统提示、历史讨论、来源分析或正文。

Novel OS 为此连接实施 **120,000 字节（含 1,024 字节封装预留）**的发送前保护。超过就明确拒绝并建议更大上下文连接；不会截断故事、自动转附件或换模型。此值低于审阅版本的默认内联阈值，是保守工程保护，不能保证阈值以内每次都完整理解。如果网关阈值被另行下调，仍需重新验证。

建议先在短请求中验证候选模型。多轮头脑风暴也可能变长，不能只按“头脑风暴”名称认定一定可用。全局骨架、大规模来源阅读、长历史应保留已有大上下文连接。未来若改善网关附件或上游容量，必须实测再调整限制；不通过丢弃原文来制造成功。

- 通过只能证明本次长度五个抽样位置可读；不证明全文每个细节被理解、真实型号、小说质量、未来稳定性或更大容量。
