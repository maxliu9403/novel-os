# 五个 Tag 生成式创作升级

2026-11-06，已部署至 `http://localhost:5174/creative-types`。范围是用户指定的 Action、Dark Romance、Possessive、Badboy、Age Gap。没有扩展为其余所有 Tag 的内容重写。

## 启用内容

| Tag | 当前知识版本 | 重点 |
| --- | --- | --- |
| Action | v1，新增 | 有明确目标与代价的行动；行动与亲密关系互相改变 |
| Dark Romance | v3 | 吸引与危险共同来源、秘密与道德代价、具体情感回报 |

| Age Gap | v2 | 成年人的人生阶段、经验与未来选择，区分年龄差与暗黑控制 |

方法原文在 `resources/novel-knowledge/tags/`，均关联 `genre.romance`。Action 属本次编辑新增，不宣称从未提供的语料统计中推导。

五份文档不再要求固定十章节拍、场地、同一种人物权力关系或统一封面。保留经典反击、揭露、公开站队、偏爱与关系修复等可选机制，要求用具体人物目标、选择、代价与读者回报形成不同因果链。它们不是固定的五个剧情段落，也不要求每章全覆盖。Synopsis、正文和封面使用同一组类型身份，各取适用指导。

## 引擎实现

- 现有 Markdown 边界支持 `novel-knowledge.v2` 与1–3个合法、不重复的 Tag roles。无需新数据库、并行工作流或新的模型响应字段。
- `knowledge-compiler.v3` 按阶段投影；探索阶段有发散路线，正文、规划与联合审稿保留执行要求，避免反复重新设计全书。每次组合解释只注入一次。
- 每份类型核心仍进入全部相关阶段；来源 SHA、选择快照、投影清单和正文交接沿用现有合同。编译版本与文档类型不一致会明确拒绝。
- 旧 YAML 和原文 Tag 编译保持原结果。旧文件不自动改写，现有小说已采用的事实与冻结方法不变化。
- 阅读预览显示新版作用，作者仍只维护一个 Markdown。
- [维护格式](../design/genre-tag-studio-v1/generative-tag-markdown.md)说明分节、角色和阶段输入。

## 文学验收范围

工程验证证明内容正确到达请求，不证明模型一定写得好。本轮没有创建小说或自动运行文学评估。下一次作者测试可以选择 Romance 与这五个 Tag，观察模型提出的路线是否在人物目标、秘密、主要冲突和代价上不同，而不只是换名字场地。

验收关注：开篇是否出现具体关系吸引和冲突；每个标签是否改变人物行动或阅读感受；较早是否有真实回报；推进与终局是否由已采用的选择产生。允许经典商业路线，不把偏离套路本身当成质量。若混选尚未升级的其他 Tag，旧文档的固定节拍仍存在；本轮未做全库去重或跨作品相似性检测。
