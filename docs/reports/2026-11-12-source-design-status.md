# 资料库整书设计状态

已开发并完成回归，尚未部署或重启服务。运行中的作品和资料任务未被操作；正式环境仍沿用上一轮发布。

## 用户可见变化

资料列表和书籍详情独立展示整书设计状态：尚未设计、设计中、设计已暂停、设计待处理、路线就绪，以及读取失败时的状态待同步。旧阅读分析状态继续保留，避免“分析完成”遮蔽正在进行的路线设计。

列表支持按全部、设计中、已暂停、待处理、路线就绪筛选，并显示数量。顶部汇总实际运行的设计任务数，卡片展示创作方式和已保存步骤，不把步骤比例包装成完成时间或整本小说完成率。新建头脑风暴的参考小说选择项和详情同步显示设计状态。

点击资料默认打开其当前设计对应的创作方式。首次进入后将方式固定到页面地址，后台新进度不会擅自切换编辑器；筛选、刷新或再次点击当前资料均保持未提交意见。开始、暂停、继续设计后立即刷新列表；后台运行期间每三秒同步，闲置时每十五秒同步。网络失败保留上次状态并重试，隐藏页面停止列表/详情定时读取，重新进入时立即同步。

## 状态来源与历史兼容

`api/source_route_status.py` 为列表和路线详情提供共同的只读投影：真实活动 worker 优先，再按最近更新时间选择运行。旧运行恢复、同时存在多个创作方式时，摘要与详情使用同样的顺序。`active_run` 仅代表实际活动任务。

持久状态仍为 prepared/queued/running 但 worker 已消失时，显示可恢复的暂停/中断状态，不能无限显示设计中。失败、需要作者选择、容量问题和结果未知显示待处理；损坏元数据不能被伪装成成功或拖垮整个资料列表。没有新设计的旧资料返回尚未设计，无须迁移旧分析。

资料接口追加 `design` 摘要，包含状态、活动数量、历史运行数量、当前运行身份、创作方式、操作和已保存步骤。只读取运行状态和 worker 关联元数据，不加载整书原文、完整路线产物或付费回复，不产生模型调用，也不自动恢复或修改设计任务。原 `study` 合同保留，工作区隔离沿用现有来源目录。
