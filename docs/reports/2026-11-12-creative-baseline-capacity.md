## 用户可见行为

- 资料库直接带入、新建页导入、已有路线讨论与无资料原创共用创作基线。新路线操作明确采用核心走向与情绪回报；历史方向选择不自动扩大为全路线授权。空构想的有效路线会话可创建、修改设置、继续讨论和生成骨架。
- 独立核对完整新增设计，保护人物选择、代价、关系变化、情绪回报、重要看点及因果。兼容的细节可以主动深化；作者明确改线通过原话见证生效，原路线仍保留。未采用选项、假设和原作事实不混同。
- 全部讨论标签都能看到骨架准备提示。没有问题不等于故事完成；明确区分继续探索、确认篇幅、可生成骨架及需要恢复。不自动开始骨架或正文。
- 路线同一次生成给出目标语言对应的总篇幅、章数、每章字数和场面理由。推荐可改，基础设置中后改的值优先，返回步骤不恢复旧推荐；旧路线缺推荐时，首次实质讨论主动给出篇幅方案。
- 篇幅方案支持总字数、章数、每章上限、逐章目标和已确认方案重新编辑。在原场景允许范围内重新分配只做本地计算；需要重新分章或估算时才调用模型。无法容纳时说明需要的空间，保留剧情与旧方案。
- 纯解释和未采用选项比较不废弃已有篇幅。明确结构化提问只保存解释，不发表模型附带的地图、骨架或篇幅；自由文本由同一次独立核验确认无设计变化后保留旧方案，附可追溯的可用性绑定。

## 后端边界与恢复

`core/creative_baseline.py` 从现有作者原话、决定、路线快照与有效故事设计派生依据，不建立第二份真相账本。原件哈希保持；稳定承诺 ID 与有效采用范围分离。`creative_amendments.py` 记录独立核验过的具体作者改线，复合提案不能因为只改结局就全部丢弃。

`core/creative_development.py` 保存完整候选和依据，执行一次范围内独立核验，按需要取回原文或历史端点。具体问题仅授权精确字段修复；写范围与只读依赖分开，宿主验证范围外未改动。存在修复时再次核验，未变且实际依赖未变的通过页可复用。协议纠正和请求恢复沿用 `SourceRequestSession`，无无限自重试。

`api/workshop_development.py` 是共同晋级接点。生成先保存，通过后才能更新当前设计、地图、篇幅和骨架；未通过候选不混入已采用对话。恢复复用已保存生成与核验回执；下一次明确继续修订也使用保留候选。新的作者引用独立进入篇幅证据范围，不改绑旧生成的来源回执。

最终交付核验读取实际 Markdown，通过 `workshop_development_delivery.py` 无损拆分完整章节和全局叙事，兼容六节和历史十七节，保留旧宿主生成的 JSON 附录、原始多行标题与完整补充记录。修复不能改章节身份、标题、篇幅、分类或宿主合同。宿主包装和作者选定书名另记完整前后哈希链；采用编辑建议后审核修订稿，不重新生成整本骨架。

`creative-handoff.v6` 冻结原始基线、独立核验、有效作者改线和真实章节落点。落点必须引用实际已读章节中的叙事，不能用 ID 或标题证明情绪已兑现。已有 v1–v5 合同及运行锁保持原路径。GET 不迁移；旧任务下一次明确新操作接入，旧运行中操作恢复原合同。重新推导归档旧 development，不能继承上轮解释、篇幅操作或交付凭据。

## 100 章与小上下文

- 原始资料、作者原话、候选、历史和检查点完整保存；不以删文或摘要替代必要证据。核验按完整章节分页，全局及有效核心完整提供，跨章关系按精确地址取回两端。
- 隔离替身测试：100 章候选 167,609 字节、历史 275,040 字节，一次局部修复请求 7,222 字节；全部原件仍在。另一组 100 章实际渲染在 24KB 测试容量下分页，末章取得首章实际证据后继续。
- 运行时 `creative-runtime-basis.v1` 提供有效约束、完整作者要求、改线见证与落点。未采用讨论和旧候选保留在冻结锁中，按精确地址取证。238KB 历史的默认请求由 255,573 字节降为 19,992 字节；需要读取全部历史时，128KB 同一连接使用现有无损证据分页，恢复不重复调用。
- `SourceRequestSession` 和请求容量仍负责诚实停止：不可分的单条核心本身超过连接容量，或未知远端响应不能恢复时，不伪造通过，不丢证据，也不无限重购。测试证明传输、范围与恢复行为，不构成真实小说文学质量的绝对保证。

## 相对提案的明确调整

原提案希望复用已有交付审稿。代码核实后发现：现代 story-first 的最终骨架是本地渲染，原来没有独立的路线履约审稿；历史十七节带编辑建议审核。现增加共同的候选基线核验，历史编辑建议仍保留其原职责。普通新增设计通常增加一次独立检查；证据不足、具体修复、真实作者改线或章节分页才有条件追加。明确结构化解释不买核验，纯排版/书名不重审叙事；自然语言解释在同一次核验判断影响，不增加单独意图分类调用。
